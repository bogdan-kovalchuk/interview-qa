## Short answer

Звуження цілого типу може змінити значення; у перетворенні до беззнакового типу результат визначається остачею за модулем `U_MAX + 1`.[^iso-c-n1570] Наприклад, за наявності 8-бітного `uint8_t`, перетворення `300` дає `44`, бо `300 mod 256 = 44`.[^iso-c-n1570] Таке перетворення відбувається при присвоєнні, передаванні аргументу або поверненні значення, якщо цільовий тип вужчий. Перевіряйте діапазон до перетворення, коли втрата значення не є задумом.

## Detailed explanation

Звуження відбувається, коли значення цілого типу перетворюють на тип із меншим діапазоном, наприклад присвоюють у змінну `uint8_t`. Поняття «відкидання старших бітів» корисне для пояснення конкретного беззнакового перетворення, але не є універсальним описом усіх звужень: правила залежать від знаковості та представлення цільового типу.[^iso-c-n1570]

Для беззнакового типу стандарт визначає результат як єдине значення, еквівалентне початковому за модулем на одиницю більше за максимальне значення типу. Для 8-бітного `uint8_t` це модуль 256. Отже, якщо `int` може представити 300, присвоєння 300 до `uint8_t` дає 44. При цьому машинне представлення може пояснювати результат відкиданням старших бітів, але мовне правило формулюється через модуль, а не через конкретну інструкцію процесора.[^iso-c-n1570]

Перетворення до знакового цілого типу, якщо значення не представиме, має інше правило: результат є implementation-defined або може виникнути implementation-defined сигнал. Тому не можна переносити приклад із `uint8_t` на `int8_t` і робити висновок лише за бітами. Аналогічно, попередження компілятора залежить від прапорців та конкретного випадку; не слід покладатися на те, що кожне неявне звуження буде діагностоване.[^iso-c-n1570]

Приклад для `uint8_t`:
```c
int x = 300;
uint8_t y = (uint8_t)x; /* y == 44, якщо uint8_t існує */
```

Перетворення може статися в присвоєнні, аргументі функції з цільовим типом меншого діапазону або під час повернення значення. Якщо вихідне значення повинно зберегтися, перевірте межі перед перетворенням; якщо modulo-поведінка задумана, зробіть її явною і задокументуйте.

**Типова помилка:** пояснювати всі звуження як гарантоване відкидання старших бітів. Для беззнакового результату спирайтеся на правило modulo, а для signed narrowing перевіряйте окремі правила стандарту та компілятора.[^iso-c-n1570]

## Short answer

Формально: `memset` встановлює всі байти в 0. IEEE 754 `0.0f` = bit pattern `0x00000000` -> на практиці працює.

Але: стандарт C не гарантує що float нуль = всі байти нуль (теоретично). Більша проблема: `memset(struct_ptr, 0, sizeof(*struct_ptr))` для struct з `void*` - <span class="warn">NULL pointer</span> не гарантовано bit-pattern 0x0 за стандартом (хоча практично так).

Краща практика: явна ініціалізація кожного поля.[^iso-c-n1570]

## Detailed explanation

`memset(p, 0, sizeof *p)` записує нуль у кожен байт області пам’яті, але це не те саме, що присвоїти нульове значення кожному полю структури. За C11 представлення арифметичних типів визначається реалізацією; стандарт не вимагає, щоб нуль `float` мав усі нульові біти. Null pointer також є значенням вказівника, а не обов’язково нульовою адресою чи бітовим шаблоном з нулів.[^iso-c-n1570]

На поширених MCU з IEEE 754 `float` бітове подання `0.0f` зазвичай складається з нульових бітів. Тому байтове обнулення часто працює для числових полів у конкретному toolchain, але спирається на ABI та реалізацію. Перевіряйте документацію компілятора й цільової платформи, якщо код покладається на це.[^iso-c-n1570]

Навіть якщо нульові байти дають нульове число, вони можуть не задавати правильних значень для інших полів – вказівників, enum або типів із особливим представленням. Типізований ініціалізатор застосовує правила мови до кожного поля:

```c
struct State { float value; void *context; };
struct State state = { .value = 0.0f, .context = NULL };
```

**Типова помилка:** вважати, що «усі біти нуль» означає «усі поля мають нульові значення». Для конкретного embedded target це може бути прийнятим контрактом, але його слід перевірити для кожного поля. Перевірте формат floating-point, представлення вказівників і правила ABI; не робіть висновок лише з успішного тесту на одному compiler build.[^iso-c-n1570]

Функція `memset` працює на рівні байтів і не знає типів полів. Навіть якщо конкретний ABI використовує нульове представлення для `0.0f`, це гарантія саме цієї платформи, а не переносиме правило мови. C11 окремо визначає нульове значення вказівника як результат перетворення цілого константного виразу зі значенням 0; це не вимагає, щоб об’єктне представлення вказівника складалося з нульових байтів.[^iso-c-n1570]

Для масиву структур або повторного скидання стану застосовуйте ту саму дисципліну: явно присвоюйте нуль числовим полям і `NULL` вказівникам або використовуйте типізований compound literal. Так компілятор виконує потрібне перетворення до кожного типу, а код не залежить від побайтового кодування значень.[^iso-c-n1570]

## Short answer

`malloc(size)` виділяє `size` байтів без ініціалізації, а `calloc(n, size)` виділяє масив із `n` елементів по `size` байтів і встановлює всі байти в нуль; нульові байти не обов’язково є семантичним нулем для кожного типу.[^iso-c-n1570]

Обидві функції повертають `NULL`, якщо пам’ять виділити не вдалося. Перед використанням результат перевіряють на `NULL`, а для потрібних значень елементів виконують явну ініціалізацію.[^iso-c-n1570]

## Detailed explanation

`malloc(size)` запитує один блок заданого розміру в байтах. Успішний виклик повертає вказівник на виділену пам’ять, але її вміст не ініціалізується; читати значення до запису потрібних даних не можна. Якщо запит не вдається, повертається null pointer.[^iso-c-n1570]

`calloc(n, size)` призначений для виділення пам’яті під масив із `n` елементів по `size` байтів і встановлює всі байти отриманого простору в нуль. Це саме нульове бітове подання, а не загальна обіцянка, що кожен елемент будь-якого типу матиме семантичне значення нуля. Зокрема, стандарт C не вимагає, щоб усі нульові біти утворювали null pointer або значення floating-point `0.0`; для переносимого створення об’єктів потрібної семантики слід присвоїти їм коректні значення мовою C.[^iso-c-n1570]

Окремий плюс `calloc` – два параметри явно виражають кількість елементів і розмір кожного. На відміну від обчислення `n * size` у коді перед `malloc`, бібліотечна функція може перевірити переповнення добутку; поведінку конкретної бібліотеки й версії стандарту варто звіряти з її контрактом. Якщо вручну обчислений добуток переповниться і стане замалим, подальший запис масиву вийде за межі блока.[^iso-c-n1570]

Приклад: для масиву з десяти елементів `uint32_t` типовий запит має форму `calloc(10, sizeof(uint32_t))`. Перед використанням результат потрібно перевірити на `NULL`. Якщо програма очікує семантичний початковий стан, явно встановіть потрібні значення елементів, замість припускати, що нульові байти дорівнюють нулю для будь-якого типу.[^iso-c-n1570]

**Типові помилки:**
- Називати невизначений вміст `malloc` «випадковими» даними: стандарт просто не задає початкового значення.
- Вважати нульове бітове подання еквівалентом нульового значення кожного можливого типу.
- Не перевіряти повернене значення на `NULL` перед записом у блок.[^iso-c-n1570]

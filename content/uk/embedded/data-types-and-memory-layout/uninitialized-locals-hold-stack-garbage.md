## Short answer

Локальний об’єкт з automatic storage duration без явного ініціалізатора має невизначене (indeterminate) значення; стандарт C не вимагає, щоб він лежав саме у стеку. Ініціалізатор на кшталт `int x = 0;` задає визначене початкове значення, а об’єкти зі static storage duration мають окремі правила нульової ініціалізації. Читання indeterminate значення не є надійним способом отримати залишкові байти стека і, залежно від виразу та типу, може бути undefined behavior.[^iso-c-n1570][^embeddedinterviewlab]

## Detailed explanation

Локальна змінна з автоматичною тривалістю зберігання без явного ініціалізатора має невизначене значення; стандарт C не вимагає, щоб вона фізично лежала на `stack`.[^iso-c-n1570]

Компілятор може розмістити локальну змінну в регістрі, у стековому кадрі або взагалі усунути її, якщо це зберігає спостережувану поведінку програми. Тому «локальна» описує область видимості, а автоматична тривалість зберігання – час існування об’єкта, а не конкретну адресу в RAM.[^iso-c-n1570]

Ініціалізатор на кшталт `int count = 0;` задає початкове значення мовою C. Він не обов’язково відповідає окремій інструкції запису: оптимізатор може тримати значення в регістрі або спростити код. Для об’єктів зі статичною тривалістю зберігання правила інші: арифметичні об’єкти без ініціалізатора отримують нульове значення; startup code типової embedded-системи копіює `.data` з образу та очищує `.bss`, але ці секції не є способом ініціалізувати локальні автоматичні змінні.[^iso-c-n1570]

Читання невизначеного значення не слід пояснювати як гарантовані «випадкові байти з попереднього виклику». Залежно від типу й конкретного виразу наслідки можуть бути undefined behavior; це не надійне джерело стану. Наприклад, `int sum; sum += x;` читає старе невизначене значення `sum` до першого присвоєння, тож підсумок не має коректної початкової точки.[^iso-c-n1570]

**Типові помилки:**

- Ототожнювати область видимості з місцем фізичного зберігання.
- Очікувати, що debugger або попередній запуск гарантує нуль у локальній змінній.

**Приклад:**

```c
int sum = 0;
for (unsigned i = 0; i < n; ++i)
    sum += values[i];
```

Ініціалізуйте кожен об’єкт до першого читання й використовуйте тип, який відповідає діапазону даних. У налагодженні перевіряйте попереднє присвоєння, а не покладайтеся на те, що стековий кадр випадково містив потрібне число.[^iso-c-n1570]

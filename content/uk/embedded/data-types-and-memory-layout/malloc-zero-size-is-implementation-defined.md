## Short answer

За C11 `malloc(0)` має implementation-defined поведінку: реалізація документує, чи повертає `NULL`, чи вказівник, який не можна використовувати для доступу до об’єкта.[^iso-c-n1570] Обробляй нульовий розмір окремо й явно визначай семантику порожнього буфера; це не забороняє передавати ненульовий результат у `free`. Поведінка embedded allocator має відповідати його документації.

## Detailed explanation

`malloc(0)` не надає місця для жодного об’єкта, а стандарт C дозволяє реалізації вибрати й задокументувати результат такого виклику.[^iso-c-n1570] Це не те саме, що звичайна помилка виділення: для додатного розміру `NULL` означає, що пам’ять не виділено, тоді як нульовий запит має окрему, implementation-defined поведінку.

Якщо результат ненульовий, його можна передати `free`, але він не дає права читати чи записувати байти. Розіменування такого вказівника не створює об’єкт і не перетворює нульову довжину на мінімальний буфер. Не можна покладатися на те, що два нульові запити дадуть однаковий вказівник або різні вказівники; це не контракт програми.[^iso-c-n1570]

Надійний API заздалегідь визначає семантику порожньої послідовності. Він може повернути успіх із довжиною нуль і не викликати allocator, або відхилити такий ввід, якщо порожній буфер заборонений. Це рішення має бути явним і однаковим на всіх платформах. Перевірка лише `p != NULL` недостатня: ненульовий результат усе одно не означає, що існує доступний байт.

Перед множенням кількості елементів на їхній розмір перевіряють нуль і переповнення, а потім викликають виділення. Інакше переповнення може перетворити великий запит на нульовий, а наступний код помилково використає результат як звичайний буфер. В embedded-системі allocator може бути власною реалізацією, тому поведінка має спиратися на документований контракт платформи й програми.[^iso-c-n1570]

**Типова помилка:** трактувати будь-який ненульовий результат як адресу щонайменше одного байта. Для порожнього масиву збережи довжину нуль і не виконуй доступ через вказівник; якщо інваріант структури вимагає непорожню пам’ять, відхили запит до виклику `malloc`.

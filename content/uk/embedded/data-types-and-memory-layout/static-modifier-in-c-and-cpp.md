## Short answer

**У C:**
- Локальна змінна: `static int cnt = 0;` – зберігає стан між викликами.
- Глобальна змінна/функція: `static void helper()` – видима лише в поточному `.c` файлі.[^dou-embedded-interview]

**Додатково у C++:**
- Статичний член класу: `static int count;` – один для всіх об’єктів, ініціалізується поза класом.
- Статичний метод: `static void reset();` – викликається як `MyClass::reset()`, не має доступу до `this`.

## Detailed explanation

Модифікатор `static` є фундаментальним інструментом керування життєвим циклом об’єктів та областю видимості імен як у процедурному C, так і в об’єктно-орієнтованому C++. Хоча ключове слово спільне, мова C++ суттєво розширила його контексти та змінила правила ініціалізації.[^iso-c-n1570] [^iso-cpp-n4861]

### Використання модифікатора `static` у мові C

У мові C модифікатор `static` застосовується виключно до змінних та функцій у двох синтаксичних позиціях (а також у спеціальній формі масивів-параметрів C99):[^iso-c-n1570]

1. **Локальні змінні у функціях (Static Storage Duration):**
   - Змінна, оголошена всередині функції як `static`, зберігає своє значення між послідовними викликами цієї функції.[^iso-c-n1570]
   - Вона розміщується не на стеку викликів, а в статичній пам’яті (секція `.data` для ненульових ініціалізованих значень або `.bss` для нульових).
   - Область видимості залишається суто блочною (block scope), що забезпечує збереження стану без винесення змінної в глобальний простір імен.
   - За стандартом C ініціалізація локальної статичної змінної константним виразом виконується один раз до старту `main()` (під час виконання startup-коду мікроконтролера).
2. **Глобальні змінні та функції файлового рівня (Internal Linkage):**
   - Оголошення функції чи глобальної змінної зі словом `static` обмежує її видимість поточною одиницею трансляції (translation unit).[^iso-c-n1570]
   - Символ позначається в об’єктному ELF-файлі як локальний (`LOCAL`), тому лінкер не дозволяє іншим `.c`-файлам зв’язуватися з ним. Це захищає від колізій імен у великих проєктах і слугує основним засобом приховування деталей реалізації драйверів (приватні статичні функції та буфери).
3. **Кваліфікатор розміру масиву в параметрах функцій (C99):**
   - Стандарт C99 запровадив синтаксис `void process_buffer(uint8_t buf[static 16])` (§6.7.6.3). Ключове слово `static` всередині квадратних дужок повідомляє компілятору, що фактичний аргумент не є нульовим вказівником (`NULL`) і вказує на масив щонайменше з 16 елементів. Це дозволяє оптимізатору агресивно розгортати цикли та використовувати векторні SIMD-інструкції без додаткових перевірок.[^iso-c-n1570]

### Розширені можливості `static` у мові C++

Мова C++ зберегла всі можливості мови C, додавши нові контексти для підтримки класів та безпечної ініціалізації:[^iso-cpp-n4861]

1. **Статичні члени-дані класу (Static Data Members):**
   - Статичне поле належить безпосередньо класу, а не окремим його екземплярам. Існує рівно одна копія такого поля на всю програму.[^iso-cpp-n4861]
   - Поле не займає місця всередині структури об’єкта (`sizeof(Class)` його не включає).
   - До стандарту C++17 статичні члени класу вимагали обов’язкового визначення поза класом в окремому `.cpp`-файлі: `int MyClass::count = 0;`. Починаючи з C++17 дозволено `inline static int count = 0;`, що спрощує створення header-only бібліотек.
2. **Статичні методи класу (Static Member Functions):**
   - Метод класу, оголошений як `static`, не прив’язаний до екземпляра і не отримує прихованого покажчика `this`.[^iso-cpp-n4861]
   - Він може звертатися лише до статичних полів або інших статичних методів цього класу.
   - Викликається безпосередньо через ім’я класу: `MyClass::reset()`.
   - Завдяки звичайній конвенції виклику статичний метод можна використовувати як точку входу для потоків або callback-функцію в C-сумісних бібліотеках (наприклад, задача FreeRTOS чи обробник таймера).
3. **Потокобезпечні локальні статики (Magic Statics у C++11):**
   - На відміну від C, у C++ локальні статичні змінні можуть ініціалізуватися динамічно (наприклад, викликом конструктора або функції під час першого виконання).
   - Стандарт C++11 гарантує, що така ініціалізація є потокобезпечною (thread-safe): якщо кілька потоків або задач RTOS одночасно намагаються пройти точку оголошення, компілятор гарантує однократний виклик конструктора без стану гонитви.[^iso-cpp-n4861]
4. **Безіменні простори імен замість `static` у C++:**
   - Для обмеження видимості символів поточною одиницею трансляції стандарт C++ рекомендує використовувати безіменні простори імен (`unnamed / anonymous namespaces`): `namespace { ... }` замість ключового слова `static` на файловому рівні. Це дозволяє приховувати не лише змінні та функції, а й користувацькі типи (структури, класи, переліки).

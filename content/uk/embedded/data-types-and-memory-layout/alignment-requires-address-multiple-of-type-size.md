## Short answer

Alignment – вимога до адреси об'єкта, визначена реалізацією для його типу; вона не обов'язково дорівнює розміру типу. `_Alignof(T)` у C повідомляє вимогу вирівнювання типу `T`.

Доступ за невирівняною адресою може бути повільнішим або забороненим, залежно від процесора, інструкції та області пам'яті; не кожне ядро обробляє його однаково.[^iso-c-n1570]

## Detailed explanation

Alignment визначає, які адреси підходять для об'єкта певного типу. У C вимога вирівнювання є властивістю типу та реалізації; `_Alignof(T)` дає її числове значення. Вона не визначається загальним правилом «адреса кратна `sizeof(T)`», бо розмір об'єкта і його alignment – різні характеристики.[^iso-c-n1570]

Наприклад, тип може займати 8 байтів, але вимагати вирівнювання на межу 4 байти. Точні значення залежать від ABI, компілятора та цільової архітектури. Для структур компілятор може додавати padding між полями або в кінці структури, щоб кожен її елемент масиву починався з належної адреси.[^iso-c-n1570]

На рівні процесора наслідок misaligned access також залежить від контексту: одна інструкція чи пам'ять може підтримувати такий доступ, а інша – вимагати alignment або спричиняти fault. Тому твердження на кшталт «усі Cortex-M падають на невирівняному слові» некоректне без назви ядра, інструкції, налаштувань і типу пам'яті.[^iso-c-n1570]

У C alignment також впливає на допустимість перетворень покажчиків: результат перетворення має бути правильно вирівняний для цільового типу, інакше поведінка не визначена стандартом. Це окрема мовна вимога від того, чи здатна конкретна інструкція CPU фізично прочитати байти за такою адресою.[^iso-c-n1570]

Padding у структурі допомагає компілятору розмістити кожне поле на придатній межі, а розмір структури може включати додаткове доповнення, потрібне для масиву таких структур. Тому не можна безпечно серіалізувати структуру як незмінний набір байтів між різними ABI: padding, розміри типів і alignment можуть відрізнятися.[^iso-c-n1570]

Якщо байти зовнішнього протоколу треба інтерпретувати як багатобайтове ціле, типовий переносний підхід – зібрати значення з байтів або скопіювати їх через `memcpy` у правильно вирівняний об'єкт, а endian-ність обробити окремо. Так код не покладається на те, що довільна адреса байтового буфера задовольняє alignment цілого типу.[^iso-c-n1570]

**Типова помилка:** обчислити адресу, вважаючи `sizeof(T)` автоматично вимогою alignment. Для портативного C використовуйте належно вирівняні об'єкти та `_Alignof(T)`; для конкретної MCU звіряйтеся з її документацією і налаштуваннями компілятора.

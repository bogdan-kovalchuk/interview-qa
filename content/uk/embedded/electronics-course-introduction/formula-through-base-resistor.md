## Short answer

<span class="formula">\(I_B\)</span> = (<span class="formula">\(V_{in}\)</span> − <span class="formula">\(V_{BE}\)</span>) / <span class="formula">\(R_B\)</span>. Де <span class="formula">\(V_{in}\)</span> – напруга джерела сигналу, <span class="formula">\(V_{BE}\)</span> ≈ 0.7 В, <span class="formula">\(R_B\)</span> – резистор у базовому колі. Приклад: <span class="formula">\(V_{in}\)</span> = 5 В, <span class="formula">\(R_B\)</span> = 3.3 кОм -> <span class="formula">\(I_B\)</span> = (5 − 0.7) / 3300 ≈ 1.3 мА.[^udemy-electronics-course]

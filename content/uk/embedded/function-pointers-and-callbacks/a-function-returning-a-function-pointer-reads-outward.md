## Short answer

Приклад без typedef:

`int (*select_op(int id))(int, int);`

Це означає: `select_op` приймає `int` і повертає pointer на функцію, яка приймає два `int` і повертає `int`. Через typedef краще: `typedef int (*op_t)(int, int); op_t select_op(int id);`

Правило: якщо декларацію важко прочитати з першого разу, typedef зазвичай робить тип виразнішим.[^iso-c-n1570]

## Detailed explanation

Функція C не може повертати іншу функцію як значення, але може повертати вказівник на функцію. Тому декларація має описувати `select_op` як функцію з параметром `int`, результатом якої є function pointer; сам вказівник посилається на функцію з двома параметрами `int` і результатом `int`. Обмеження мови забороняє функціональний тип як тип результату, тоді як вказівник на функцію є допустимим об’єктним типом результату.[^iso-c-n1570]

У `int (*select_op(int id))(int, int)` спочатку читаємо `select_op(int id)`: це функція з аргументом `id`. Далі `*` у дужках означає, що її результат – вказівник; зовнішній `(int, int)` описує функцію, на яку вказує результат. Дужки навколо `*select_op(int id)` критичні: без них оголошення читалося б інакше через правила пріоритету декларатора. Стандарт C наводить такий самий принцип у прикладі функції, що повертає вказівник на функцію.[^iso-c-n1570]

Варіант із псевдонімом розбиває тип на частини: `typedef int (*op_t)(int, int);` задає тип callback, а `op_t select_op(int id);` задає функцію-вибирач. Це спрощує читання й дає змогу повторно використовувати той самий тип у масивах, структурах і параметрах. Проте `typedef` не змінює тип і не робить несумісні сигнатури сумісними.[^iso-c-n1570]

**Типові помилки:**

- Оголосити функцію, що нібито повертає функцію, пропустивши `*` або дужки.
- Переплутати параметри `select_op` із параметрами функції, яку він повертає.
- Сприймати `typedef` як новий окремий тип замість псевдоніма.

На практиці після отримання вказівника перевіряйте контракт функції-вибирача: чи повертає вона придатний callback для кожного допустимого `id`, і чи може результат бути нульовим. Перш ніж викликати результат як `select_op(id)(a, b)`, треба гарантувати, що він вказує на сумісну функцію; виклик через function pointer несумісного типу має undefined behaviour.[^iso-c-n1570]

## Short answer

Так:

`return (x > y) - (x < y);`

Повний фрагмент: `const int x = *(const int *)a; const int y = *(const int *)b;`. Такий comparator повертає `1`, `0` або `-1` без signed overflow.

Правило: comparator має послідовно визначати порядок для тих самих значень; знак результату `qsort` використовує як less, equal або greater.[^iso-c-n1570]

## Detailed explanation

Безпечний comparator не віднімає значення, щоб вивести їхній порядок. Він спершу читає кожен аргумент як вказівник на фактичний тип елемента, а потім застосовує оператори порівняння. Для `int` це `const int *`; перетворення потрібні, бо `qsort` передає адресу кожного елемента через параметри `const void *`.[^iso-c-n1570]

Вираз `(x > y) - (x < y)` складається з двох relational expressions. Кожен із них дає `0` або `1`; їхня різниця може бути лише `-1`, `0` або `1`. Отже, обчислення не залежить від того, наскільки далеко значення розташовані одне від одного, і не намагається представити `x - y` у `int`. Це усуває ризик signed overflow для повного діапазону `int`.[^iso-c-n1570]

Приклад повного comparator-а для масиву `int`:

```c
int compare_ints(const void *a, const void *b)
{
    const int x = *(const int *)a;
    const int y = *(const int *)b;
    return (x > y) - (x < y);
}
```

Якщо `x` менше за `y`, перший порівняльний вираз дорівнює нулю, а другий – одиниці, отже результат `-1`. Якщо значення рівні, обидва вирази нульові й comparator повертає `0`. Якщо `x` більше, маємо `1`. Це точно відповідає контракту `qsort`: повернути від’ємне, нульове або додатне значення відповідно до порядку двох елементів.[^iso-c-n1570]

Метод працює за умови, що обидва вказівники справді вказують на елементи типу `int`, як і передбачає виклик `qsort` з правильним `size`. Він не виправляє хибний тип масиву, неправильний розмір елемента чи порушений строк життя даних. Також `qsort` не є стабільним сортуванням: якщо comparator повертає нуль, стандарт не обіцяє зберігати початковий порядок рівних елементів.[^iso-c-n1570]

**Типові помилки:**

- Помилково записати `(x > y) - (x < y)` навпаки – тоді порядок стане спадним.
- Вважати, що cast виправляє випадок, коли аргумент насправді вказує на елемент іншого типу.
- Очікувати від `qsort`, що рівні елементи залишаться у вихідному порядку.

Для іншого елементного типу збережіть ту саму схему знака, але правильно прочитайте поля, за якими визначається порядок. Якщо потрібне стабільне сортування, використовуйте алгоритм із такою гарантією або додайте початковий індекс як tie-breaker.[^iso-c-n1570]

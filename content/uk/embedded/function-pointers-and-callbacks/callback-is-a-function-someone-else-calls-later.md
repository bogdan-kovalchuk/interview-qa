## Short answer

**Callback** – це функція, адресу якої передають іншому коду, щоб той викликав її пізніше при певній події або умові.[^iso-c-n1570]

У C callback найчастіше реалізується function pointer-ом. Наприклад, driver UART викликає callback при отриманні байта, timer – при timeout, parser – коли знайшов frame, а `qsort` – коли треба порівняти два елементи.

Правило інтерв’ю: function pointer – механізм; callback – роль або pattern використання цього механізму.[^iso-c-n1570]

## Detailed explanation

Callback – це функція, яку один компонент передає іншому, щоб той викликав її у визначений момент, наприклад після події або завершення операції. Ідея полягає в інверсії керування: клієнт надає дію, а компонент, який знає коли вона потрібна, вирішує, коли її виконати.

У C найчастіше передають function pointer. Його тип задає контракт виклику: тип результату й параметри мають бути сумісними з функцією, яку зареєстрували. Наприклад, драйвер може приймати callback для повідомлення про байт, а timer – функцію для виклику після спливання інтервалу. Callback сам по собі не означає окремий потік або автоматичну асинхронність: його можуть викликати синхронно в тому самому потоці чи контексті, де працює API.[^iso-c-n1570]

Поширений варіант API додає `void *ctx`, щоб клієнт міг передати власний стан без глобальних змінних. Реєстратор зберігає і callback, і цей контекст, а під час події передає контекст назад. Власник має гарантувати, що об’єкт контексту живий протягом усіх можливих викликів; інакше callback отримає застарілий вказівник. Також контракт API повинен пояснити, хто й коли викликає callback, чи можна його викликати повторно та як скасувати реєстрацію.

Приклад: застосунок передає UART-драйверу `on_rx(ctx, byte)`. Драйвер викликає її після приймання байта; сам драйвер не мусить знати, чи застосунок кладе байт у чергу, оновлює лічильник або передає його parser.

**Типові помилки:**

- Називати будь-який function pointer callback, навіть якщо ніхто не реєструє його для подальшого виклику.
- Припускати, що callback завжди запускається пізніше або в іншому потоці.
- Звільнити контекст до того, як компонент припинив викликати callback.

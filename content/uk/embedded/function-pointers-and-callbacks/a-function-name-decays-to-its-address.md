## Question code

```c
int add1(int x) { return x + 1; }
int (*op)(int) = add1;
printf("%d", op(41));
```

## Short answer

Виведе `42`, якщо фрагмент оточений потрібними оголошеннями та `printf` доступний.

Ім’я функції `add1` у цьому присвоєнні перетворюється на pointer to function, тож `op = add1` еквівалентно `op = &add1`. Виклик `op(41)` викликає функцію через покажчик; у C обидві форми виклику `op(41)` та `(*op)(41)` дозволені.[^iso-c-n1570]


## Detailed explanation

Function designator – це вираз із типом функції, наприклад `add1` у наведеному коді. За правилом C він у більшості виразів автоматично перетворюється на pointer to function відповідного типу. Винятки включають операнд унарного `&` та безпосередній операнд виклику, тож короткий запис `add1(41)` теж працює без проміжного покажчика.[^iso-c-n1570]

Оголошення `int (*op)(int)` читається від імені `op`: це покажчик на функцію, що приймає `int` і повертає `int`. Під час `op = add1` тип функції `add1` перетворюється на сумісний function pointer. Форма `&add1` також має тип pointer to function і дає те саме значення для цього звичайного випадку. Відповідність сигнатури має значення: функція з несумісними типами параметрів або результату не стає коректним призначенням лише тому, що її адреса зберігається у покажчику.

У виразі `op(41)` правила виклику застосовуються до покажчика на функцію. Унарне розіменування також дає function designator, тому `(*op)(41)` є еквівалентним записом. Додаткові дужки часто використовують, щоб підкреслити непрямий виклик, але вони не змінюють результат. Тут `add1` повертає `41 + 1`, отже `printf` друкує число `42`.

Приклад:

```c
int add1(int x) { return x + 1; }
int (*op)(int) = add1;
int result = op(41);  /* result is 42 */
```

Важливо відрізняти перетворення function designator від виклику функції: у початковому присвоєнні `add1` не виконується, бо немає дужок виклику. Покажчик зберігає можливість обрати функцію зараз, а виконати її пізніше. Це основа callback-ів і таблиць функцій; проте сам тип покажчика має збігатися з типом цільової функції згідно з мовними правилами.[^iso-c-n1570]

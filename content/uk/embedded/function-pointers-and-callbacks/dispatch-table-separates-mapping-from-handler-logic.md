## Short answer

**Вона зберігає відповідність opcode -> handler окремо від реалізацій обробників** і може спростити додавання команд.

У parser протоколу таблиця може зібрати вибір обробника в одному місці, тоді як кожна функція реалізує окрему команду. Це структурна перевага, а не гарантія меншого коду чи швидшого виконання.

Для кількох гілок `switch` часто простіше читати; таблиця доречна, коли mapping є даними або набір команд розширюється. Продуктивність визначають вимірюванням, а не формою запису.[^iso-c-n1570]

## Detailed explanation

Dispatch table – це масив function pointers, де позиція або ключ команди визначає функцію, яку треба викликати. Вона відділяє рішення «який opcode відповідає якому handler» від коду, який виконує саму команду; тип function pointer задає сумісну сигнатуру для елементів таблиці та виклику.[^iso-c-n1570]

Це допомагає, коли mapping є окремою частиною протоколу: таблицю можна переглянути як перелік команд, а реалізацію кожного handler – змінювати незалежно. Додавання команди часто зводиться до нового елемента та функції. Утім, якщо команди мають складні умови, параметри чи різні сигнатури, проста таблиця може приховати логіку або вимагати додаткових структур і перевірок.[^iso-c-n1570]

Таблиця також не гарантує автоматично меншого бінарного файлу чи швидшої роботи. Компілятор може перетворити `switch` на таблицю переходів або згенерувати послідовність порівнянь; function pointer call має непрямий target. Для обмежень часу виконання чи пам’яті порівнюй зібраний код і вимірювання на цільовому MCU, а не припускай перевагу за синтаксисом.[^iso-c-n1570]

Приклад:

```c
typedef void (*handler_t)(void);
static handler_t handlers[] = { handle_ping, handle_reset };
```

Перед викликом індекс усе одно перевіряють на межі масиву, а оброблювані вхідні дані – на валідність. Інакше компактна диспетчеризація перетворюється на шлях до undefined behavior або небажаного handler виклику.[^iso-c-n1570]

**Типові помилки:**

- Вважати dispatch table завжди швидшою або коротшою за `switch`.
- Забувати межі таблиці під час індексації.
- Змішувати вибір handler із перевіркою, чи дозволено виконувати команду.[^iso-c-n1570]

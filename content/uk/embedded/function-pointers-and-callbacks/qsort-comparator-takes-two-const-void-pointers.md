## Short answer

Сигнатура comparator-а: `int cmp(const void *a, const void *b)`.[^iso-c-n1570]

Він повертає negative, zero або positive value, щоб сказати, чи перший елемент менший, рівний або більший за другий. Усередині callback треба привести `a` і `b` до pointer на реальний тип елементів.

Правило: `qsort` не знає тип елементів; function pointer callback повертає йому type-specific comparison logic.[^iso-c-n1570]

## Detailed explanation

Comparator для `qsort` – це функція, що приймає два вказівники `const void *` і повертає `int`. Саме таку сигнатуру задає стандартна бібліотека C для параметра `compar` у `qsort`.[^iso-c-n1570]

Кожен аргумент указує на один елемент масиву, а не на весь масив. Оскільки функція сортування універсальна й отримує розмір елемента окремо, її comparator не має конкретного типу даних у сигнатурі. Усередині нього програміст перетворює кожен аргумент на вказівник на реальний тип елемента, зберігаючи `const`, а тоді порівнює значення. Для масиву `int` це, наприклад, `const int *`; для масиву структур – вказівник на відповідну `const struct`.[^iso-c-n1570]

Знак результату задає порядок: від’ємне значення означає, що перший елемент іде перед другим, нуль – що comparator вважає їх рівними для сортування, додатне – що перший має йти після другого. Потрібно повернути лише правильну категорію знака; конкретні `-1` і `1` не є обов’язковими. Алгоритм може викликати comparator багато разів і в різному порядку, тому результат має відповідати одному й тому самому правилу порівняння.[^iso-c-n1570]

Приклад: для масиву цілих чисел comparator отримує адресу двох окремих елементів, читає кожен як `const int`, а потім визначає їхній порядок. Він не повинен змінювати елементи через ці вказівники, бо аргументи мають тип вказівника на `const void`. Якщо два елементи вважаються рівними, `qsort` не гарантує збереження їхнього початкового взаємного порядку.[^iso-c-n1570]

**Типові помилки:**

- Оголосити параметри як `const void` замість `const void *`: `void` не є типом повного об’єкта, на який можна вказувати.
- Порівнювати адреси аргументів замість значень елементів.
- Вважати, що comparator мусить повертати тільки `-1`, `0` або `1`; контракт вимагає лише від’ємне, нульове або додатне значення.

Перевірте також, що `size` під час виклику `qsort` дорівнює `sizeof` фактичного типу елементів і що comparator трактує адреси відповідно до того самого типу.[^iso-c-n1570]

## Short answer

У **PWM** timer рахує період і порівнює counter з duty value, керуючи output pin. **Input capture** зберігає counter на edge для вимірювання часу, а **output compare** генерує подію/зміну pin при match. **One-pulse** запускає одноразовий імпульс заданої тривалості після trigger.[^dou-embedded-interview]

## Detailed explanation

Апаратні таймери сучасних мікроконтролерів є багатофункціональними периферійними блоками, здатними керувати вихідними сигналами та вимірювати вхідні імпульси без постійного втручання центрального процесора. Базова архітектура таймера включає тактовий дільник (Prescaler, `PSC`), основний лічильник (Counter, `CNT`), регістр автоперезавантаження (Auto-Reload Register, `ARR`) та один або кілька каналів захоплення/порівняння (Capture/Compare Registers, `CCR`).[^st-an4013]

### Output Compare (Вихідне порівняння)

У режимі Output Compare апаратний блок порівнює поточне значення лічильника `CNT` зі значенням у регістрі каналу `CCRx`:
- Коли значення `CNT` збігається з `CCRx`, таймер генерує подію збігу (Compare Match), виставляє прапорець переривання і може автоматично змінити стан відповідного виводу GPIO.
- Доступні конфігурації виводу: перемикання стану (Toggle), встановлення високого рівня (Set High), встановлення низького рівня (Set Low) або збереження поточного стану (Frozen).
- Режим часто використовується для формування точних часових позначок, періодичних імпульсів фіксованої частоти або синхронізації запуску АЦП (ADC Trigger) без затримок у ядрі.

### Pulse Width Modulation (ШІМ / PWM)

ШІМ є розширенням режиму Output Compare і служить для генерування сигналів зі змінним коефіцієнтом заповнення (Duty Cycle) при фіксованій частоті:[^st-an4013]
- **Edge-aligned (по вирівнюванню фронту):** лічильник рахує від 0 до `ARR`. При нульовому значенні вивід стає активним (наприклад, High), а в момент рівності `CNT == CCRx` вивід перемикається в неактивний стан (Low). Період сигналу визначається значенням `ARR + 1`, а тривалість активного імпульсу – значенням `CCRx`.
- **Center-aligned (по центру):** лічильник рахує від 0 до `ARR`, а потім назад до 0 (Up-Down mode). Це вдвічі знижує електромагнітні завади (EMI) та забезпечує симетричне керування ключами у силовій електроніці й приводах двигунів (FOC / BLDC).
- **Preload/Shadow регістри:** оновлення `CCRx` та `ARR` відбувається через тіньові (shadow) регістри. Запис нового значення з програми потрапляє в буферний регістр, а в активний робочий контур переноситься лише в момент події оновлення (Update Event при переповненні лічильника). Це виключає ризик генерації некоректних укорочених імпульсів (glitches).

### Input Capture (Вхідне захоплення)

Режим призначений для високоточного вимірювання часових параметрів зовнішніх цифрових сигналів:[^st-an4013]
- Вхідний сигнал із піна GPIO надходить через програмований цифровий фільтр та детектор фронтів (Rising, Falling або обидва).
- При появі активного фронту апаратна логіка миттєво копіює поточне значення `CNT` у регістр `CCRx` і виставляє прапорець захоплення `CCxIF` (який може згенерувати переривання в NVIC або DMA-запит).[^cmsis-core-nvic]
- Вимірювання періоду та частоти виконується обчисленням різниці між значеннями `CCRx` двох послідовних однакових фронтів: `Delta = CCR_new - CCR_old`. Завдяки модульній арифметиці лічильника результат залишається правильним навіть при переході лічильника через нуль, якщо тривалість не перевищує один повний період таймера.
- Режим застосовується для опитування енкодерів, вимірювання обертів тахометрів, ультразвукових датчиків (відлуння HC-SR04) та декодування протоколів (IR NEC, PPM, PWM-радіокерування).

### One-Pulse Mode (Режим одного імпульсу)

One-Pulse Mode поєднує можливості вхідного тригера та вихідного порівняння:
- Таймер перебуває в очікуванні зовнішнього імпульсу на лінії тригера (зовнішній пін, компаратор або інший таймер через шину тригерів TRGO/ITR).
- При отриманні тригера таймер автоматично запускає лічильник.
- Після затримки, яка визначається значенням `CCRx`, вивід перемикається в активний стан, а після досягнення `ARR` повертається в неактивний стан.
- У цьому режимі біт увімкнення таймера автоматично скидається апаратно після завершення імпульсу (`OPM` біт у регістрі керування зупиняє лічильник при першому ж оновленні).
- Це гарантує генерацію рівно одного імпульсу із заданою затримкою та тривалістю на апаратному рівні, повністю усуваючи джиттер програмного коду.

## Short answer

**Булева алгебра** – математична система для значень істина/хиба або 1/0.[^dou-embedded-interview] Базові операції: AND (`&&` або логічне множення), OR (`||` або логічне додавання), NOT (`!`), а також XOR.

В електроніці вона описує логічні вентилі й цифрові схеми, а в програмуванні – умови, маски, флаги та оптимізацію логічних виразів. Наприклад, закони Де Моргана: `!(A && B) == (!A || !B)` і `!(A || B) == (!A && !B)`.

## Detailed explanation

### Математичний базис та аксіоматика

Булева алгебра – це розділ математичної логіки, що оперує множиною двох елементів `{0, 1}` (хиба / істина, Low / High) та трьома базовими операціями:
1. **Кон’юнкція (AND)**: позначається як множення (`A * B` або `A ∧ B`), дає `1` тоді й лише тоді, коли обидва операнди дорівнюють `1`.
2. **Диз’юнкція (OR)**: позначається як додавання (`A + B` або `A ∨ B`), дає `1`, якщо хоча б один із операндів дорівнює `1`.
3. **Заперечення (NOT)**: інверсія (`~A`, `!A` або `NOT A`), змінює `0` на `1` і навпаки.

Похідною, проте критично важливою для цифрової техніки є операція **виключного АБО (XOR)**: `A ^ B = (A * !B) + (!A * B)`, яка повертає `1` лише тоді, коли стани входів різняться.

Фундаментальні закони булевої алгебри дозволяють спрощувати логічні рівняння:
- **Ідемпотентність**: `A * A = A`, `A + A = A`.
- **Поглинання**: `A + (A * B) = A`, `A * (A + B) = A`.
- **Дистрибутивність**: `A * (B + C) = (A * B) + (A * C)`, а також подвійна форма `A + (B * C) = (A + B) * (A + C)`.
- **Доповняльність**: `A * !A = 0`, `A + !A = 1`.
- **Закони де Моргана**:
  - `!(A * B) = !A + !B`
  - `!(A + B) = !A * !B`

### Апаратна реалізація у цифровій схемотехніці

У фізичній цифровій електроніці та архітектурі процесорів булеві операції реалізуються за допомогою логічних вентилів (Logic Gates) на базі CMOS-транзисторів:
- **Базиси NAND та NOR**: у технології CMOS логічні елементи із запереченням на виході (NAND і NOR) є швидшими, меншими за площею на кристалі та енергоефективнішими, ніж неінвертуючі елементи (AND складається з елемента NAND плюс інвертор NOT). Елементи NAND і NOR є функціонально повними (універсальними базисами Шейффера та Пірса), тобто будь-яка цифрова схема довільної складності (від 1-бітного суматора до 64-бітного ALU) може бути побудована виключно на вентилях одного типу.
- **Мінімізація схем**: за допомогою карт Карно (K-maps) або алгоритмів синтезу (Квайна – Мак-Класкі) складні логічні умови мінімізуються для скорочення кількості вентилів та зменшення часу затримки поширення сигналу (propagation delay) у критичних шляхах.
- **Таблиці пошуку (LUT)**: у програмованих логічних інтегральних схемах (FPGA) булеві функції реалізуються не фіксованими вентилями, а таблицями перекодування (Look-Up Tables, наприклад 4-LUT чи 6-LUT), які зберігають таблицю істинності будь-якої комбінаційної функції від N входів.

### Побітові операції та керування регістрами в C

В embedded-програмуванні булева логіка використовується на двох концептуальних рівнях згідно зі стандартом C [^iso-c-n1570]:
1. **Логічні операції в умовах (`&&`, `||`, `!`)**: оперують істинністю виразу в цілому (нуль – хиба, будь-яке ненульове число – істина) і підтримують коротке замикання (short-circuit evaluation).
2. **Побітові операції (`&`, `|`, `^`, `~`, `<<`, `>>`)**: застосовують булеві операції паралельно до кожного окремого біта машинних слів. Це основа взаємодії з апаратною периферією мікроконтролера:

```c
// Встановлення біта (Set bit через OR)
USART1->CR1 |= USART_CR1_UE;

// Скидання біта (Clear bit через AND з інверсною маскою)
USART1->CR1 &= ~USART_CR1_M;

// Інверсія біта (Toggle bit через XOR)
GPIOA->ODR ^= (1U << 5);

// Перевірка стану біта (Test bit через AND)
if ((USART1->SR & USART_SR_RXNE) != 0U) {
    uint8_t data = (uint8_t)USART1->DR;
}
```

### Закони де Моргана у прошивках та оптимізація умов

У розробці систем реального часу та написанні драйверів закони де Моргана є основним інструментом спрощення складних сторожових умов і перевірок статусу периферії:
- Умова виходу за таймаутом або відсутністю помилок: вираз `!((status & BUSY) && (retries > 0))` за законом де Моргана еквівалентний `!(status & BUSY) || (retries <= 0)` (для беззнакового `retries` – `retries == 0`). Друга форма читається як пряма умова виходу, але порядок обчислення в обох формах однаковий: якщо `status & BUSY` дорівнює нулю, `retries` не обчислюється ні в `&&`, ні в `||`.[^iso-c-n1570]
- Формування масок очищення прапорців переривань: для скидання кількох бітів помилок одночасно об’єднання масок `~(ERR_PARITY | ERR_FRAMING | ERR_OVERRUN)` перетворюється компілятором в єдину операцію завантаження константи без необхідності окремих операцій інверсії для кожного прапорця.

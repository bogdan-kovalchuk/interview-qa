## Short answer

Виробникові плати потрібні файли Gerber RS-274X, по файлу на шар: мідь кожного шару, паяльна маска, паста для трафарету й шовкографія. Окремо йде файл свердління з координатами й діаметрами отворів. Для автоматичного монтажу додають файл pick-and-place з координатами й поворотом кожного компонента, а також перелік елементів.[^udemy-electronics-course]

## Question code

```c
union U { float f; uint32_t u; };
union U x;
x.f = 1.0f;
uint32_t bits = x.u;
```

## Short answer

<span class="warn">Пастка не в C-синтаксисі, а в переносимості результату і різниці C vs C++.</span>

У C дозволено інтерпретувати представлення union через інший член, але отримане значення може бути implementation-defined і може мати trap representation. У C++ читання inactive union member здебільшого не дозволене, крім вузьких винятків для common initial sequence.

Для копіювання байтів без порушення правил aliasing використовуй `memcpy`; у C++20 також є `std::bit_cast`. Це не гарантує однакового числового результату на платформах із різними представленнями типів.[^iso-c-n1570]

## Detailed explanation

Type punning через `union` означає запис одного типу-члена, а потім читання того самого сховища через інший член. Такий код виглядає як простий спосіб побачити біти `float`, проте його правила різняться між C і C++, а значення залежить від представлень типів та платформи.[^iso-c-n1570]

У C стандарт описує випадок, коли значення зберігається в одному члені union, а читається через інший. Представлення зчитаного значення відповідає байтам активного члена; якщо це представлення є trap representation для типу читання, це undefined behavior. В інших випадках результат не слід трактувати як переносне числове значення: стандарт допускає implementation-defined аспекти, а формат `float` та порядок байтів не універсальні.[^iso-c-n1570]

У C++ інша модель часу життя об’єктів. Читання члена, відмінного від активного, загалом не є допустимим; є вузький виняток для common initial sequence у стандарт-layout структур, що лежать у спільній частині union. Отже приклад із `float` та `uint32_t` не можна автоматично переносити з C у C++ і називати однаково коректним.[^iso-c-n1570]

**Приклад:** після `x.f = 1.0f;` вираз `x.u` не виконує перетворення `1.0f` на ціле число. Він намагається прочитати те саме сховище як цілий тип. Якщо потрібна саме копія бітового представлення, перевірте, що типи мають однаковий розмір, і скопіюйте байти через `memcpy`; для C++20 підходить `std::bit_cast` за умов його вимог. Навіть тоді результат має сенс лише за відомого представлення `float` і порядку байтів.[^iso-c-n1570]

**Як пастка проявляється:** тест може показувати очікувану константу на одному MCU/compiler, а після зміни оптимізації або цільової платформи давати інший результат. Щоб уникнути цього, розрізняйте числове перетворення і копіювання object representation, користуйтеся відповідною мовною операцією та документуйте припущення формату.[^iso-c-n1570]

## Short answer

`struct` – агрегатний тип, який об’єднує кілька полів різних або однакових типів під одним іменем.[^dou-embedded-interview] На відміну від масиву, поля можуть мати різні типи: `struct Point { int x; int y; };`.

Структури використовують для моделювання об’єктів даних, пакетів протоколів, конфігурацій, записів таблиць, descriptor-ів і register map-ів. Доступ до поля: `s.x` для об’єкта і `p->x` для вказівника на структуру. Розмір структури може бути більшим за суму полів через padding і alignment.

## Detailed explanation

### Стандартне визначення структури в C

Структура (`struct`) у мові C – це агрегатний тип даних, який складається з послідовності іменованих елементів (членів або полів), типи яких можуть відрізнятися[^iso-c-n1570]. На відміну від масиву, де всі елементи обов’язково однотипні, структура дозволяє об’єднати логічно пов’язані змінні різного розміру й типу в єдину сутність.

Стандарт гарантує, що поля структури розташовуються в пам’яті послідовно в тому порядку, у якому вони оголошені у вихідному коді[^iso-c-n1570]. При цьому адреса структури завжди збігається з адресою її першого поля (offset 0), тому приведення вказівника на структуру до вказівника на тип її першого поля є коректною операцією.

### Вирівнювання (alignment) та байти заповнення (padding)

Апаратні архітектури (зокрема ARM Cortex-M) оптимізовані для доступу до даних за адресами, кратними їхньому природному розміру: 16-бітні значення – за парними адресами, 32-бітні слова – за адресами, кратними 4. Щоб задовольнити ці вимоги, компілятор вставляє байти заповнення (`padding`)[^iso-c-n1570]:
- **Внутрішній padding**: розміщується між полями структури. Наприклад, якщо після поля `uint8_t` (1 байт) оголошено `uint32_t` (4 байти), компілятор вставить 3 байти заповнення.
- **Кінцевий padding (trailing padding)**: додається наприкінці структури, щоб весь розмір `sizeof(struct)` був кратним найбільшому вирівнюванню серед її полів. Це необхідно для коректного вирівнювання елементів при розміщенні структур у масиві.

```c
// Неоптимальне розташування: sizeof = 12 байтів
struct Inefficient {
    uint8_t  a;    // 1 байт + 3 байти padding
    uint32_t b;    // 4 байти
    uint8_t  c;    // 1 байт + 3 байти trailing padding
};

// Оптимізоване розташування: sizeof = 8 байтів
struct Efficient {
    uint32_t b;    // 4 байти
    uint8_t  a;    // 1 байт
    uint8_t  c;    // 1 байт + 2 байти trailing padding
};
```

Згідно зі стандартом викликів ARM AAPCS, складений тип (структура) вирівнюється за своїм найбільш суворо вирівняним членом. Якщо структура містить 64-бітне поле (наприклад, uint64_t), її вирівнювання становить 8 байтів, а при передачі як аргумент функції через регістри вона повинна починатися з парного регістра (R0 або R2), навіть якщо це залишає непарний регістр вільним.

### Застосування у низькорівневих прошивках

1. **Відображення апаратних регістрів (Register Maps)**: Стандарт CMSIS описує периферійні блоки мікроконтролерів як структури зі специфікатором `volatile`, де зміщення полів точно відповідають фізичним адресам регістрів периферії:
   ```c
   typedef struct {
       volatile uint32_t CR1;
       volatile uint32_t CR2;
       volatile uint32_t SR;
       volatile uint32_t DR;
   } USART_TypeDef;
   ```
2. **Пакети протоколів зв’язку**: Формування кадрів CAN, пакетів SPI/I2C чи дескрипторів передачі даних DMA.
3. **Таблиці конфігурації та драйверів**: Збереження параметрів ініціалізації периферії у Flash (`.rodata`).

### Відмінності між C та C++

- У **мові C** ім’я структури живе в окремому просторі імен тегів (`tag namespace`), тому для створення змінних без `typedef` вимагається префікс `struct MyStruct s;`[^iso-c-n1570]. Крім того, структури в C не можуть містити методи чи конструктори.
- У **мові C++** `struct` є повноцінним класом із єдиною відмінністю: за замовчуванням рівень доступу до членів та базових класів є `public` (у `class` – `private`)[^iso-cpp-n4861]. Вона може містити методи, конструктори та віртуальні функції.

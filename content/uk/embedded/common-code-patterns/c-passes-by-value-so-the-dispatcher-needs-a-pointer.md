## Short answer

<span class="warn">У C параметр функції отримує власне значення аргументу</span> – зміна локального `state` не змінює змінну виклику. FSM означає finite state machine.[^iso-c-n1570]

```c
// баг: правиться лише копія
void process(state_t state, ...);
// fix: правиться справжній стан
void process(state_t *state, ...);
```

Тип `enum` сам собою не змінює правило передавання аргументів.

Щоб диспетчер змінив стан виклику, передай адресу й запиши через вказівник; перевір його на `NULL`, якщо це дозволяє контракт функції.[^iso-c-n1570]

## Detailed explanation

У C параметр функції є окремим локальним об’єктом, ініціалізованим значенням відповідного аргументу. Тому функція `process(state_t state)` може змінити лише свою копію; після повернення змінна виклику лишається незмінною. Це правило однакове для цілих типів, `enum` та вказівників: навіть вказівник передається за значенням, але його копія все ще може вказувати на той самий об’єкт.[^iso-c-n1570]

Для диспетчера finite state machine це означає, що передавання `state` напряму не збереже перехід. Передавання `&state` дає функції адресу об’єкта, а присвоєння через `*state` змінює саме його. Наприклад, якщо поточний стан `IDLE` і обробник отримує подію запуску, він може записати `RUNNING` у переданий об’єкт. Після повернення код виклику побачить новий стан.

Вказівник має бути дійсним і вказувати на об’єкт, що лишається живим під час виклику. Функція також не повинна зберігати адресу локальної змінної виклику для використання після її завершення. Якщо змінювати об’єкт не потрібно, доречний параметр-значення; якщо потрібно змінити об’єкт – передають його адресу або використовують інший явний канал результату, наприклад повернене значення.[^iso-c-n1570]

**Типові помилки:**

- Змінити параметр-значення й очікувати, що caller отримає оновлення.
- Вважати, що `enum` поводиться інакше за інші об’єктні типи.
- Передати нульовий або вже недійсний вказівник і розіменувати його.

Перевіряй сигнатуру й місце виклику разом: аргумент має бути адресою саме того стану, який має пережити виклик.

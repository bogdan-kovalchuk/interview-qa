## Short answer

`&` AND – скидання біта: `reg &= ~(1<<n)` `|` OR – встановлення біта: `reg |= (1<<n)` `^` XOR – інвертування: `reg ^= (1<<n)` `~` NOT – побітова інверсія `<<` зсув вліво: `x << 3` = x × 8 `>>` зсув вправо: `x >> 1` = x / 2.

Типові патерни в Embedded: Перевірити біт: `if (reg & (1<<n))` Встановити: `reg |= (1<<n)` Скинути: `reg &= ~(1<<n)` Перемкнути: `reg ^= (1<<n)`.[^dou-embedded-interview]

## Detailed explanation

### Побітові операції над регістрами периферії (MMIO)

У вбудованих системах доступ до апаратної периферії (GPIO, таймери, шини I2C/SPI/UART) здійснюється через регістри, відображені в адресний простір пам’яті (Memory-Mapped I/O, MMIO) [^armv7m-arm]. Керування функціоналом чипа відбувається шляхом маніпуляцій з окремими бітами [^iso-c-n1570]:

```c
#define LED_PIN (5U)

// 1. Встановлення біта (Set)
*GPIO_ODR |= (1U << LED_PIN);

// 2. Скидання біта (Clear)
*GPIO_ODR &= ~(1U << LED_PIN);

// 3. Інверсія біта (Toggle)
*GPIO_ODR ^= (1U << LED_PIN);

// 4. Перевірка біта (Test)
if (*GPIO_IDR & (1U << LED_PIN)) {
    // Вхідний рівень високий (HIGH)
}
```

### Проблема Read-Modify-Write та гонитва станів (Race Conditions)

Класичні складені оператори `|=`, `&=`, `^=` виконують так званий цикл читання-модифікації-запису (Read-Modify-Write, RMW). На асемблерному рівні мікроконтролера ARM Cortex-M команда `reg |= (1U << n)` транслюється у три послідовні машинних кроки:
1. `LDR r0, [r1]` – читання поточного значення регістру в РОН (регістр загального призначення).
2. `ORR r0, r0, r2` – логічна модифікація значення в процесорному ядрі.
3. `STR r0, [r1]` – запис оновленого значення назад в апаратний регістр.

Якщо в проміжку між `LDR` та `STR` виникає апаратне переривання (ISR), обробник якого модифікує інший біт цього ж самого регістра, після повернення з переривання інструкція `STR` затре зміни, зроблені в ISR. Це класична помилка гонитви станів (`race condition`), яка призводить до плаваючих апаратних збоїв.

### Апаратні методи забезпечення атомарності

Для уникнення блокування глобальних переривань мікроконтролери надають спеціалізовані апаратні механізми [^armv7m-arm]:

1. **Регістри Set/Clear (BSRR / BRR у STM32, OUTSET / OUTCLR у NRF/SAM)**:
   Замість читання регістра виводу використовується спеціальний регістр атомарного запису:
   ```c
   // Атомарне встановлення піна 5 (запис 1 у молодшу половину BSRR)
   GPIOx->BSRR = (1U << 5);

   // Атомарне скидання піна 5 (запис 1 у старшу половину BSRR)
   GPIOx->BSRR = (1U << (5 + 16));
   ```
   Запис одиниці виконує апаратну дію, а запис нуля повністю ігнорується внутрішньою логікою. Це усуває фазу читання і робить операцію атомарною за одну транзакцію шини `STR`.

2. **Апаратний механізм Bit-Banding (ARM Cortex-M3 / M4)**:
   Архітектура ARMv7-M виділяє спеціальну область адресного простору (`bit-band alias region`), де кожному окремому біту периферії або оперативної пам’яті відповідає власне 32-бітне слово пам’яті [^armv7m-arm]. Запис значення `0` або `1` за цією псевдоадресою виконується контролером шини AHB як неподільна атомарна апаратна транзакція без циклу RMW у ядра процесора.

3. **Особливості скидання прапорців переривань (RC_W1)**:
   У багатьох периферійних модулях прапорці статусу мають семантику `rc_w1` (Read-only, Clear by Writing 1). Спроба очистити прапорець через `STATUS &= ~(1U << FLAG)` помилково прочитає всі інші активні прапорці і запише їх назад одиницями, випадково скинувши події інших переривань. Для таких регістрів очищення виконується прямим записом одиниці лише у потрібний біт: `STATUS = (1U << FLAG)`.

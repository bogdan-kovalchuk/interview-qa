## Question code

```c
#define BIT32(n) (UINT32_C(1) << (n))
```

## Short answer

**Set / Clear / Toggle / Test:**

```c
reg |=  BIT32(n);   // set
reg &= ~BIT32(n);   // clear
reg ^=  BIT32(n);   // toggle
if (reg & BIT32(n)) { ... } // test
```

Set – OR, clear – AND з інверсією маски, toggle – XOR, test – AND.

`n` має бути в діапазоні 0–31 для 32-bit маски. Для memory-mapped register перевір документацію: звичайний read-modify-write може бути непридатним, якщо регістр має спеціальну семантику запису або змінюється апаратурою.[^iso-c-n1570]

## Detailed explanation

Бітова маска вибирає один біт у цілому числі чи регістрі. `BIT32(n)` створює маску з одиницею у позиції `n`; цей макрос спирається на `UINT32_C(1)` з `<stdint.h>`, а `n` має бути від 0 до 31. Зсув на ширину типу чи більше не є коректним способом отримати бітову маску в C.[^iso-c-n1570]

Set об’єднує значення з маскою через OR, тому вибраний біт стає 1, а інші лишаються як були. Clear застосовує AND з інверсією маски, щоб вибраний біт став 0. Toggle через XOR змінює лише вибраний біт, а test через AND перевіряє, чи цей біт уже встановлений. Для перевірки результату не обов’язково, щоб він дорівнював 1: маска повертає саме бітову позицію, тому достатньо порівняти з нулем.[^iso-c-n1570]

Для звичайної змінної це зрозумілі операції над значенням. Але запис у memory-mapped register може мати специфічну семантику: деякі регістри очищають прапорці записом одиниці, деякі мають окремі set/clear адреси, а певні біти змінюються апаратурою. У таких випадках стандартне `reg |= mask` виконує читання, зміну й запис і може стерти стороннє оновлення або записати неправильні біти. Треба користуватися процедурою з reference manual конкретного MCU, а `volatile` забезпечує лише властивості доступу, визначені реалізацією, не атомарність.[^iso-c-n1570]

Приклад для `n = 3`: маска має вигляд `00001000`. OR встановлює цей біт, AND із доповненням маски очищає його, XOR перемикає, а AND із початковим значенням показує, чи він був встановлений. Перед застосуванням перевір ширину регістра та дозволені операції читання/запису.

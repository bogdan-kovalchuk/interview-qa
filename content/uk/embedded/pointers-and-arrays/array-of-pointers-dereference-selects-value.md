## Question code

```c
int a=1,b=2,c=3;
int *arr[3]={&a,&b,&c};
printf("%d",*arr[1]);
```

## Short answer

`2`.

`int *arr[3]` – масив з 3 вказівників на `int`. `arr[1]` -> другий елемент = `&b`. `*arr[1]` -> розіменування `&b` -> значення `b = 2`.

Зберігання: `arr` – масив адрес (3 × 4 байти = 12 байт). Кожен елемент – окрема адреса; зміна `*arr[1] = 99` -> змінить `b`.[^embeddedinterviewlab]

## Detailed explanation

### Пріоритет операторів та послідовність обчислення *arr[1]

В аналізі виразу `*arr[1]` вирішальну роль відіграє пріоритет операторів стандарту C (ISO/IEC 9899, пункт 6.5).[^iso-c-n1570] Постфіксний оператор індексації масиву `[]` має найвищий пріоритет (рівень 1), тоді як унарний оператор розіменування `*` належить до другого рівня пріоритету:

1. Спочатку обчислюється підвираз `arr[1]`.
2. До отриманого результату застосовується оператор розіменування `*`.

Тобто вираз синтаксично еквівалентний `*(arr[1])`, а не `(*arr)[1]`. Оскільки `arr` оголошено як `int *arr[3]`, елемент `arr[1]` містить значення адреси змінної `b` (тип `int*`). Розіменування цієї адреси повертає безпосереднє значення змінної `b`, яке дорівнює `2`.[^embeddedinterviewlab]

### Розподіл пам’яті та модель подвійної індирекції

Структура розміщення об’єктів у пам’яті мікроконтролера в даному прикладі складається з двох рівнів:

- Змінні `a`, `b`, `c` займають по 4 байти в пам’яті (на 32-розрядній архітектурі ARM Cortex-M) і розташовані за незалежними адресами.
- Масив `arr` є неперервним блоком із трьох вказівників: `sizeof(arr) == 3 * sizeof(int*) = 12` байтів (або 24 байти на 64-бітній платформі). Кожен слот масиву зберігає 32-бітну чисельну адресу відповідної змінної.

Для отримання числа `2` процесор виконує два послідовні звернення до пам’яті:
1. Завантаження адреси `&b` з пам’яті масиву за зміщенням `arr + 1 * 4`.
2. Завантаження цілого числа за отриманою адресою з комірки пам’яті `b`.

### Модифікація значень та різниця між const-кваліфікаторами

Оскільки кожен елемент масиву зберігає безпосередню адресу цільового об’єкта, операція присвоєння через розіменування `*arr[1] = 99;` модифікує саму змінну `b` у пам’яті.

При проєктуванні драйверів важливо розрізняти положення кваліфікатора `const`:
- `const int *arr[3]` – масив вказівників на константні дані (заборонено змінювати `*arr[i]`, але можна перепризначати самі адреси `arr[i] = &x`);
- `int * const arr[3]` – константний масив змінних вказівників (адреси зафіксовані, але дані за ними можна змінювати);
- `const int * const arr[3]` – повністю незмінна таблиця адрес і значень, яку лінкер може надійно розмістити у Flash-пам’яті.

### Практичне застосування у вбудованих системах

Масиви вказівників є базовим інструментом для організації нерегулярних структур даних:
- **Таблиці рядків меню та команд (CLI):** де кожен елемент масиву вказує на текстовий рядок змінної довжини (`const char * const menu_items[]`), що суттєво економить пам’ять порівняно з двовимірним масивом фіксованої ширини `char menu[N][M]`.
- **Ланцюжки буферів DMA (Scatter-Gather):** масив дескрипторів із вказівниками на розрізнені області пам’яті пакетів для Ethernet або USB контролерів.

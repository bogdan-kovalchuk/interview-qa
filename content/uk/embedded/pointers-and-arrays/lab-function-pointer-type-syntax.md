## Short answer

`void (*fp)(int);`. Цей запис оголошує вказівник на функцію.

Читання: `fp` – вказівник (`*fp`) на функцію (`(*fp)(int)`), що повертає `void`.

Для зручності використовують псевдонім типу через `typedef`:

```c
typedef void (*callback_t)(int);
callback_t fp = my_func;
```

Для масиву з 8 покажчиків без typedef: `void (*table[8])(int);`.

Синтаксис виклику: `fp(42);` або `(*fp)(42);` – обидва варіанти є повністю валідними у C.[^embeddedinterviewlab]

## Detailed explanation

### Синтаксичні правила оголошення покажчиків на функції

У мові C оголошення типу покажчика на функцію визначається правилами пріоритету операторів (часто формулюється як правило спіралі або читання зсередини назовні). Круглі дужки виклику функції `()` та квадратні дужки масиву `[]` мають вищий пріоритет, ніж унарний оператор розіменування `*`.

Згідно зі стандартом ISO/IEC 9899:201x (C11, пункт 6.7.6.3), для оголошення змінної `fp`, яка є вказівником на функцію, що приймає `int` і повертає `void`, дужки навколо `*fp` є обов’язковими [^iso-c-n1570]:
```c
void (*fp)(int);
```
Розбір структури оголошення:
1. `(*fp)` – змінна `fp` є вказівником.
2. `(*fp)(int)` – цей вказівник адресує функцію, що приймає один аргумент типу `int`.
3. `void` – функція повертає порожній тип `void`.

Якщо дужки пропустити:
```c
void *fp(int); /* Оголошення звичайної функції fp, яка повертає вказівник void* */
```
Тут компілятор інтерпретує `fp` як функцію, що повертає покажчик на `void`, що докорінно змінює сенс виразу.

### Оголошення типів через typedef та using

Для багаторазового використання та збереження структурованості коду покажчики на функції зазвичай оформлюють через псевдоніми типів:

* **У чистому C (через `typedef`)**:
  ```c
  typedef void (*button_callback_t)(int);
  button_callback_t on_click = handle_button_press;
  ```
* **У сучасному C++ (через `using`)**:
  ```cpp
  using button_callback_t = void (*)(int);
  ```

Для створення масиву покажчиків на функції (наприклад, таблиці диспетчеризації скінченного автомата FSM) прямий синтаксис без `typedef` виглядає складно: `void (*fsm_table[4])(int);`. Використання псевдоніма робить запис наочним: `button_callback_t fsm_table[4];`.

### Застосування у мікроконтролерних прошивках (ARM Cortex-M)

Вказівники на функції є фундаментальним інструментом у низькорівневому програмуванні:
1. **Таблиця векторів переривань (Vector Table)**: у мікроконтролерах ARM Cortex-M початкова область Flash за адресою `0x08000000` (або `0x00000000`) є масивом вказівників на функції-обробники (`Reset_Handler`, `NMI_Handler`, `HardFault_Handler`, `SysTick_Handler`).
2. **Асинхронні зворотні виклики (Callbacks)**: реєстрація обробників подій апаратних таймерів, завершення транзакцій DMA або натискання кнопок.
3. **Об’єктно-орієнтований підхід та поліморфізм у C**: структури драйверів (HAL) зберігають покажчики на функції для абстракції апаратного забезпечення:
   ```c
   struct UartDriver {
       void (*init)(uint32_t baud);
       void (*send_byte)(uint8_t data);
   };
   ```

### Апаратні пастки: Thumb-біт та нульові покажчики

При роботі з покажчиками на функції в ARM Cortex-M слід враховувати апаратні вимоги архітектури:
* **Вимога Thumb bit (LSB = 1)**: ядра ARM Cortex-M підтримують виключно набір інструкцій Thumb-2. Для вказівки процесору на виконання коду в режимі Thumb молодший біт адреси функції (bit 0) обов’язково повинен дорівнювати `1`. Компілятор і лінкер виставляють цей біт автоматично при взятті адреси функції `&my_func`. Якщо виконати перехід за адресою з парним LSB (наприклад, внаслідок некоректного приведення числових адрес), процесор згенерує апаратний виняток `UsageFault` (INVSTATE – спроба перейти у стан ARM).
* **Захист від виклику нульового вказівника (NULL Pointer Dereference)**: виклик неініціалізованого покажчика передає керування на адресу `0x00000000`. Якщо там знаходиться Flash або неініціалізований адресний простір, виникає миттєвий `HardFault`. Перед викликом необхідна обов’язкова перевірка:
  ```c
  if (fp != NULL) {
      fp(42); /* Або (*fp)(42); обидва варіанти повністю легітимні за стандартом C */
  }
  ```

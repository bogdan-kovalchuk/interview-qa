## Question code

```c
int arr[3][3]={{1,2,3},{4,5,6},{7,8,9}};
printf("%d", *(*(arr+1)+2));
```

## Short answer

`6`.

`arr+1` -> вказівник на другий рядок `arr[1]` (тип `int(*)[3]`). `*(arr+1)` -> decay до `int*`, вказує на `arr[1][0] = 4`. `*(arr+1)+2` -> вказує на `arr[1][2] = 6`. `*(*(arr+1)+2)` -> значення = `6`.

Еквівалентно: `arr[1][2]`.[^embeddedinterviewlab]

## Detailed explanation

Вираз `*(*(arr + 1) + 2)` демонструє внутрішній зв’язок між синтаксисом індексації масивів `[]` та адресною арифметикою покажчиків у багатовимірних масивах згідно зі стандартом ISO/IEC 9899 (§6.5.2.1 Array subscripting, §6.5.6 Additive operators).[^iso-c-n1570]

### Покроковий розбір виразу та правила еквівалентності індексації

У мові C оператор індексації масиву `E1[E2]` за визначенням стандарту (§6.5.2.1 p2) є синтаксичним цукром для виразу `*((E1) + (E2))`:
```text
arr[i][j]  ==  (*(arr + i))[j]  ==  *(*(arr + i) + j)
```

Для масиву `int arr[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};` обчислення виразу `*(*(arr + 1) + 2)` розгортається за такими кроками:[^iso-c-n1570]

1. **`arr` (Array decay першого рівня):**
   - Тип масиву `arr` – це `int[3][3]` (масив із трьох масивів по три `int`).
   - У виразі додавання ім’я масиву зазнає decay і перетворюється на вказівник на свій перший елемент (перший рядок) – тип `int (*)[3]` (покажчик на масив із 3 елементів `int`).
2. **`arr + 1` (Крок за рядком):**
   - До покажчика додається `1`. Крок адресної арифметики дорівнює розміру об’єкта, на який він вказує: `sizeof(int[3]) = 3 * sizeof(int) = 12` байтів (на 32-бітній платформі ARM).
   - Результат `arr + 1` має тип `int (*)[3]` і вказує на другий рядок матриці (`arr[1]`).
3. **`*(arr + 1)` (Розіменування рядка та другий decay):**
   - Розіменування `*(arr + 1)` дає lvalue-вираз другого рядка – масив типу `int[3]`.
   - У наступному виразі додавання цей масив зазнає decay до покажчика на свій нульовий елемент – тип `int *`, що вказує на `arr[1][0]` (елемент зі значенням `4`).
4. **`*(arr + 1) + 2` (Крок за стовпцем):**
   - До покажчика типу `int *` додається `2`. Крок становить `sizeof(int) = 4` байти.
   - Адреса зміщується на `2 * 4 = 8` байтів уперед всередині другого рядка.
   - Отриманий покажчик адресує елемент `arr[1][2]`.
5. **`*(*(arr + 1) + 2)` (Фінальне розіменування):**
   - Оператор розіменування читає значення цілого числа за отриманою адресою.
   - Другий рядок містить значення `{4, 5, 6}`. Елемент з індексом 2 має значення **`6`**.

### Фізичне розташування в пам’яті (Row-Major Order)

Стандарт ISO/IEC 9899 (§6.2.5 p20) вимагає, щоб елементи багатовимірних масивів зберігалися у пам’яті строго неперервно рядок за рядком (row-major order):[^iso-c-n1570]

| Елемент | Значення | Зміщення від початку |
|---|---|---|
| `arr[0][0]` | 1 | +0 байтів |
| `arr[0][1]` | 2 | +4 байти |
| `arr[0][2]` | 3 | +8 байтів |
| `arr[1][0]` | 4 | +12 байтів |
| `arr[1][1]` | 5 | +16 байтів |
| `arr[1][2]` | **6** | **+20 байтів** |
| `arr[2][0]` | 7 | +24 байти |
| `arr[2][1]` | 8 | +28 байтів |
| `arr[2][2]` | 9 | +32 байти |

Формула лінеаризації адреси для 2D-масиву M x N:
```text
адреса(arr[i][j]) = базова_адреса + (i * N + j) * sizeof(int)
```
Для `arr[1][2]`: `(1 * 3 + 2) * 4 = 5 * 4 = 20` байтів зміщення від базової адреси `arr`.

### Пастка передачі багатовимірних масивів у функції

У розробці вбудованого ПЗ (наприклад, драйвери дисплеїв або обробка сигналів) типовою пасткою є плутанина між `int (*)[3]` та `int **`:[^iso-c-n1570]
- **Покажчик на масив `int (*)[3]`:** це один вказівник, який знає розмір рядка (3 елементи) і адресує неперервну матрицю в пам’яті.
- **Вказівник на вказівник `int **`:** це вказівник на таблицю адрес у пам’яті, де кожен елемент є окремим покажчиком на незалежний рядок.
- Спроба привести `arr` до `int **` (наприклад, `void process(int **matrix)`) і викликати `matrix[1][2]` призведе до того, що число `4` (значення елемента `arr[1][0]`) буде розцінено як адреса пам’яті, розіменування якої викличе `HardFault` на мікроконтролері.
- Правильна сигнатура для прийому 2D-масиву у функції: `void process(int matrix[][3])` або передача одномірного буфера `void process(int *buf, size_t rows, size_t cols)`.

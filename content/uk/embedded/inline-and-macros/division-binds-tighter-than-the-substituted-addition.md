## Question code

```c
#define HALF(x) x / 2
printf("%d", HALF(2 + 2));
```

## Short answer

Виведе `3`, а <span class="warn">не 2</span>, бо macro argument підставляється без автоматичних дужок.[^iso-c-n1570]

Розгортання: `2 + 2 / 2`. Через precedence спершу `2 / 2 = 1`, потім `2 + 1 = 3`. Очікувалося `(2 + 2) / 2 = 2`, але відсутні дужки змінюють порядок операцій.[^iso-c-n1570]

Захист: `#define HALF(x) (((x)) / 2)` -> розгортається у `(((2 + 2)) / 2) = 2`.[^iso-c-n1570]

## Detailed explanation

Функціональний макрос виконує текстову підстановку аргументу: препроцесор не обгортає переданий вираз у дужки автоматично. У цьому прикладі `HALF(2 + 2)` дає токени `2 + 2 / 2`. Оскільки ділення має вищий пріоритет за додавання, компілятор групує вираз як `2 + (2 / 2)`, що дорівнює `3`, а не половині суми.[^iso-c-n1570]

Щоб макрос зберігав задуманий порядок обчислень, зазвичай обгортають у дужки і кожне входження параметра, і весь результат: `#define HALF(x) (((x)) / 2)`. Для цього аргументу підстановка стає `(((2 + 2)) / 2)`, тому спочатку обчислюється сума, а потім ділення. Зайві дужки навколо параметра важливі, коли в аргументі є оператор нижчого пріоритету, ніж оператор у тілі макросу.[^iso-c-n1570]

Саме тіло `HALF` усе ще має іншу типову пастку: якщо аргумент має побічний ефект, макрос може обчислити його рівно один раз у цій реалізації, але це не загальна властивість усіх макросів. Наприклад, макрос `SQUARE(x) ((x) * (x))` двічі розгортає аргумент, тож `SQUARE(i++)` змінює `i` двічі й має небажану поведінку. У C-функції аргумент обчислюється один раз перед викликом, тому для нетривіальних виразів функція часто безпечніша за макрос.[^iso-c-n1570]

Приклад виправлення для показаного коду – написати `#define HALF(x) (((x)) / 2)` або використати звичайну функцію. Перевіряй розгортання подумки чи за допомогою препроцесора, а потім застосовуй правила precedence до отриманого виразу, не до того, як макрос виглядає у вихідному тексті.

**Типова помилка:** додати дужки лише навколо аргументу, наприклад `#define HALF(x) (x) / 2`, і забути захистити все тіло від використання в більшому виразі. Надійний шаблон – `#define HALF(x) (((x)) / 2)`; якщо потрібні узагальнені обчислення, обери функцію з потрібним типом.

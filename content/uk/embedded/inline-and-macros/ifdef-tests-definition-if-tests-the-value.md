## Short answer

**`#ifdef FOO`** перевіряє лише факт визначення макроса – істинно навіть для `#define FOO 0`.

`#if FOO` обчислює значення як integer-вираз: для `#define FOO 0` буде хибно, а <span class="warn">для невизначеного `FOO`</span> препроцесор підставить `0`, тобто умова буде хибною без діагностики.

Захист: для feature-флагів зі значеннями використовуй `#if defined(FOO) && FOO`, щоб не плутати «визначено» і «увімкнено».[^iso-c-n1570]

## Detailed explanation

`#ifdef FOO` є скороченням для перевірки `#if defined(FOO)`: його результат залежить тільки від того, чи зустрічалося визначення макроса до цього місця. Значення макроса не має значення, тому навіть `#define FOO 0` задовольняє умову. Натомість `#if FOO` обчислює препроцесорний цілочисловий вираз; визначене як нуль значення дає хибну умову, а ненульове – істинну.[^iso-c-n1570]

Є важлива межа: у виразі `#if` ідентифікатори, що після макропідстановки не є макросами, замінюються на preprocessing number `0` перед обчисленням. Тому `#if MISSING_FEATURE` зазвичай не повідомляє про помилку, а тихо поводиться як `#if 0`. Якщо проєкт має компілюватися у кількох конфігураціях, така тиша може приховати друкарську помилку в назві опції.[^iso-c-n1570]

Для булевого feature-flag зручна умова `#if defined(FOO) && FOO`: перша частина засвідчує наявність визначення, друга перевіряє його значення. Оператор `&&` у препроцесорному виразі короткозамикається, але невизначений ідентифікатор у другій частині однаково підставився б як нуль. Якщо макрос має бути просто маркером наявності, застосовуйте `#ifdef`, а не домовленість зі значенням.

Наприклад, із `#define FEATURE_LOG 0` гілка `#ifdef FEATURE_LOG` увійде, а `#if FEATURE_LOG` буде пропущена. Це корисне розрізнення: перший тест відповідає на «чи задана опція?», другий – «чи її числове значення ненульове?».[^iso-c-n1570]

**Як помилка проявляється:** вимкнений прапорець усе одно вмикає код, коли його перевіряють через `#ifdef`, або назва з помилкою непомітно вимикає гілку `#if`. Уникайте цього, узгодивши для кожного прапорця одну конвенцію: порожній маркер для `#ifdef` або числове 0/1 для `#if`.

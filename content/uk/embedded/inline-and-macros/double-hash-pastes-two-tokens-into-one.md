## Question code

```c
#define REG(periph, r) periph##_##r
// REG(GPIOA, ODR) -> GPIOA_ODR
```

## Short answer

**`##` склеює сусідні токени** в списку заміни макроса: тут `GPIOA`, `_` та `ODR` утворюють ідентифікатор `GPIOA_ODR`.

Аргументи поруч із `##` підставляються без попереднього розгортання їхніх макросів; для цього потрібен додатковий рівень.

Склеєний результат має бути одним валідним preprocessing token; інакше програма порушує обмеження стандарту.[^iso-c-n1570]

## Detailed explanation

`##` з’єднує написання двох preprocessing tokens по обидва боки оператора в списку заміни function-like макроса. Результат розглядається як один preprocessing token, після чого препроцесор продовжує повторне сканування для можливих макросів.[^iso-c-n1570]

У прикладі параметр `periph` стоїть ліворуч від `##`, а `r` – праворуч від другого `##`; сам символ підкреслення є середнім токеном. Тому виклик `REG(GPIOA, ODR)` дає послідовність токенів `GPIOA_ODR`. Це лише створює написання ідентифікатора: воно не перевіряє, чи оголошений такий регістр у заголовку конкретного MCU.[^iso-c-n1570]

Параметр, сусідній із `##`, підставляється без звичного попереднього розгортання аргументу. Наприклад, якщо `PORT` визначено як `GPIOA`, виклик макроса, що склеює `PORT` із суфіксом, спершу склеїть текст `PORT`, а не його заміну. Щоб отримати `GPIOA_ODR`, потрібен зовнішній макрос, який спочатку розгортає аргументи, а потім викликає макрос зі склеюванням.[^iso-c-n1570]

Приклад:

```c
#define REG_RAW(p, r) p##_##r
#define REG(p, r) REG_RAW(p, r)
#define PORT GPIOA
REG(PORT, ODR)  /* GPIOA_ODR */
```

Після склеювання утворений фрагмент повинен бути одним коректним preprocessing token. Наприклад, злиття двох фрагментів, що утворюють два окремі токени або некоректне написання, не є допустимим; `##` також не можна ставити на початку чи в кінці списку заміни.[^iso-c-n1570]

**Типові помилки:**

- Очікувати, що `##` обчислить чи перевірить сформований ідентифікатор.
- Забути додатковий рівень, коли аргумент сам є макросом.
- Передавати фрагменти, які після з’єднання не утворюють один preprocessing token.[^iso-c-n1570]

## Question code

```c
#define ARRAY_SIZE(a) (sizeof(a) / sizeof((a)[0]))
```

## Short answer

Повертає кількість елементів масиву на етапі компіляції.

<span class="warn">Trap</span>: якщо передати вказівник (зокрема масив-параметр функції, що decay-иться до pointer), `sizeof(a)` дасть розмір вказівника, і результат буде неправильний.

Захист: застосовуй лише до справжніх масивів у тому ж scope; у GCC/Clang є trick з `__builtin_types_compatible_p`, що дає compile error на pointer; у C++ – `std::size`/шаблон.[^iso-c-n1570]

## Detailed explanation

`ARRAY_SIZE(a)` ділить розмір усього масиву на розмір його першого елемента, тому результатом є кількість елементів, якщо `a` у цьому виразі має саме тип масиву. `sizeof` повертає розмір операнда в байтах, а для масиву включає всі його елементи; для вказівника воно повертає розмір самого вказівника.[^iso-c-n1570]

Ключова межа – перетворення масиву на вказівник. У параметрі функції запис `int a[]` коригується до `int *a`, тож всередині функції макрос не бачить початкової кількості елементів. На типовій платформі ділення розміру вказівника на розмір `int` може дати правдоподібне, але хибне число. Воно не є переносимим: розміри типів залежать від реалізації.[^iso-c-n1570]

```c
int values[5];
size_t n = ARRAY_SIZE(values); // 5
void consume(int values[]) {
    size_t n = ARRAY_SIZE(values); // pointer size / sizeof(int), not 5
}
```

У C передавайте довжину окремим параметром разом із вказівником або використовуйте структуру, що зберігає дані й довжину. У C++ для справжнього масиву застосовують `std::size` або шаблон, який приймає посилання на масив і виводить його extent; вказівник вони не перетворюють на інформацію про вихідну довжину.[^iso-c-n1570]

**Типові помилки:**
- Викликати макрос у функції, що отримує масив як параметр, і вважати, що розмір зберігся.
- Застосовувати його до вказівника, динамічного буфера чи масиву, переданого через API без довжини.
- Плутати кількість елементів із байтовим розміром: `sizeof(a)` саме по собі повертає байти.

Наприклад, для `int values[5]` вираз обчислює `sizeof(values) / sizeof(values[0])`, тобто п’ять. Після передавання `values` в параметр-вказівник обидва `sizeof` вже працюють з типом вказівника та типом елемента, а не з початковим масивом. Компіляторні розширення GCC і Clang можуть додати діагностику, але це не переносима властивість стандартного макросу; найнадійніший інтерфейс функції явно передає довжину.

## Question code

```c
#define STR(x) #x
printf("%s", STR(hello));
```

## Short answer

**`#x` перетворює написання аргументу макроса на string literal**: тут підставиться `"hello"`.

Це працює тільки для параметра function-like макроса, без попереднього розгортання макросів усередині аргументу. Пробіли нормалізуються, а лапки й зворотні скісні риски екрануються.

Наприклад, `STR(hello)` утворює `"hello"`; щоб спершу розгорнути вкладений макрос, потрібен додатковий рівень.[^iso-c-n1570]

## Detailed explanation

Оператор `#` у списку заміни function-like макроса перетворює написання відповідного аргументу на string literal. У прикладі препроцесор замінює `STR(hello)` на рядковий токен `"hello"`, який `printf` передає функції як C-рядок.[^iso-c-n1570]

Це не перетворення обчисленого значення виразу. Наприклад, якщо аргументом буде `1 + 2`, результатом стане рядок із написанням `1 + 2`, а не рядок `3`. Макроси, передані як аргумент, теж не розгортаються перед стрінгіфікацією: це навмисна особливість, бо препроцесор зберігає текст аргументу.[^iso-c-n1570]

Під час створення рядка пробіли між preprocessing tokens зводяться до одного пробілу, а зовнішні пробіли прибираються. Лапки та зворотні скісні риски, які вже є в токенах аргументу, екрануються у створеному string literal, щоб результат залишався коректним токеном.[^iso-c-n1570]

Приклад:

```c
#define STR(x) #x
#define VALUE 12
STR(VALUE)   /* "VALUE" */
```

У цьому прикладі `VALUE` лишається текстом. Якщо потрібне `"12"`, застосовують двоступеневий шаблон із проміжним макросом, який спочатку підставляє й розгортає аргумент, а вже потім передає його макросу зі `#`.[^iso-c-n1570]

**Типові помилки:**

- Очікувати, що `#` обчислить вираз або розгорне назву макросу.
- Забути, що `#` має стояти безпосередньо перед ім’ям параметра макросу.[^iso-c-n1570]

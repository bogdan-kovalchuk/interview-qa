## Short answer

**General Purpose Input/Output** – універсальний цифровий пін мікроконтролера, що конфігурується програмно.

Режими: `Input` (з pull-up / pull-down / floating); `Output Push-Pull` – керує HIGH/LOW; `Output Open-Drain` – керує лише LOW, HIGH через зовнішній резистор; `Alternate Function` – пін підключається до UART/SPI/I2C/Timer.

Управління через регістри: `MODER`, `ODR`, `IDR`, `BSRR` (STM32). Атомарний запис: `BSRR` встановлює або скидає біт за один цикл без ризику race condition.[^dou-embedded-interview]

## Detailed explanation

### Внутрішня апаратна структура піна GPIO
GPIO (General Purpose Input/Output) – це універсальний цифровий вивід мікроконтролера, внутрішня схема якого містить конфігуровані вхідні буфери, вихідні драйвери та схеми підтяжки, підключені до внутрішньої системної шини через контролер периферії.

Апаратна структура типового піна (наприклад, у сімействах STM32 або NXP LPC) включає:
1. **Захисні діоди (Clamping Diodes)**:
   Два діоди, підключені до шин живлення VDD та землі VSS, які захищають кристал від короткочасних сплесків напруги та електростатичного розряду (ESD). Для толерантних до 5 В пінів (Five-Volt Tolerant, FT) верхній діод відсутній або має спеціальну схему зміщення.
2. **Внутрішні резистори підтяжки (Pull-up / Pull-down)**:
   Вбудовані польові транзистори, що імітують резистори номіналом зазвичай 30–50 кОм. Дозволяють задати певний рівень (логічна '1' або '0') на плаваючому вході без зовнішніх компонентів.
3. **Тригер Шмітта (Schmitt Trigger)**:
   Вхідний буфер із гістерезисом напруги, який перетворює повільний фронт аналогового сигналу на чіткий крутий цифровий сигнал, запобігаючи паразитному деренчанню на межі перемикання логічних рівнів.

### Режими роботи виводів (Operating Modes)
- **Input Floating (Вхід без підтяжки)**:
  Вхідний буфер активний, резистори підтяжки вимкнені. Пін має високий вхідний імпеданс (Hi-Z). Якщо до нього нічого не підключено, він чутливий до електромагнітних наведень.
- **Input Pull-Up / Pull-Down (Вхід із підтяжкою)**:
  Вмикається внутрішній резистор до VDD або GND, що фіксує стабільний потенціал за відсутності зовнішнього керування (наприклад, для кнопок або датчиків типу відкритий колектор).
- **Output Push-Pull (Двотактний вихід)**:
  Вихідний каскад складається з пари комплементарних транзисторів (P-MOS та N-MOS). Верхній P-MOS активується для встановлення рівня HIGH (VDD), а нижній N-MOS – для встановлення рівня LOW (VSS). Забезпечує швидке перемикання в обидва боки та високу здатність віддавати/споживати струм (sourcing/sinking).
- **Output Open-Drain (Вихід із відкритим стоком)**:
  Верхній P-MOS транзистор апаратно вимкнений. Пін може активно притискати лінію лише до землі (LOW) через увімкнення N-MOS. Рівень HIGH встановлюється виключно зовнішнім або внутрішнім резистором підтяжки. Використовується для шин із монтажним «АБО» (Wired-AND / Wired-OR), таких як I2C, 1-Wire, та для узгодження логічних рівнів різної напруги.
- **Alternate Function (Альтернативна функція)**:
  Пін від’єднується від стандартних регістрів GPIO і підключається безпосередньо до внутрішніх периферійних блоків: UART (TX/RX), SPI (MOSI/MISO/SCK), I2C, таймерів (PWM/Capture) або CAN.
- **Analog Mode (Аналоговий режим)**:
  Цифровий вхідний тригер Шмітта та вихідні транзистори повністю знеструмлюються, щоб зменшити витік струму, а вивід підключається напряму до входу АЦП (ADC) або виходу ЦАП (DAC).

### Програмне керування та проблема Read-Modify-Write (BSRR vs ODR)
Керування пінами здійснюється через апаратні 32-розрядні регістри MMIO [^armv7m-arm].
Найпоширеніша пастка у вбудованому ПЗ пов’язана зі зміною стану піна через вихідний регістр даних `ODR` (Output Data Register):

```c
// Небезпечно! Неатомарна операція Read-Modify-Write
GPIOA->ODR |= (1 << 5); // Встановлення PA5
```
На рівні процесора ARM Cortex-M цей рядок C транслюється у три окремі асемблерні інструкції:
```assembly
LDR r1, [r0]       ; 1. Прочитати поточний стан ODR у регістр r1
ORR r1, r1, #32    ; 2. Модифікувати біт 5
STR r1, [r0]       ; 3. Записати результат назад у ODR
```
Якщо між кроками `LDR` та `STR` виникає переривання (ISR), яке змінює стан іншого піна цього ж порту (наприклад, `PA6`), після повернення з ISR інструкція `STR` затре старе значення, скасувавши зміну, зроблену в обробнику переривання. Виникає класичний стан гонитви (race condition).

**Атомарне керування через регістр BSRR (Bit Set/Reset Register)**:
Для запобігання race condition апаратний контролер GPIO в STM32 має спеціальний регістр `BSRR`:
- Запис '1' у молодші 16 бітів (`BS0`–`BS15`) атомарно встановлює відповідний пін у стан HIGH.
- Запис '1' у старші 16 бітів (`BR0`–`BR15`) атомарно скидає відповідний пін у стан LOW.
- Запис '0' не має жодного ефекту.
Завдяки цьому зміна стану піна виконується однією атомарною інструкцією запису `STR`:
```c
// Атомарно, безпечно для ISR, без блокування переривань
GPIOA->BSRR = (1 << 5);        // Встановити PA5
GPIOA->BSRR = (1 << (5 + 16)); // Скинути PA5
```

### Швидкість перемикання (Slew Rate) та електромагнітна сумісність
Регістр конфігурації швидкості (`OSPEEDR`) дозволяє обирати швидкість наростання фронту вихідного сигналу (Low, Medium, High, Very High Speed):
- Висока швидкість необхідна для високочастотних сигналів (SPI на 40 МГц або SDIO).
- Для низькочастотних сигналів (світлодіоди, кнопки, реле) надмірно круті фронти створюють сильні високочастотні завади (ringing, overshoot/undershoot, EMI) та імпульсні кидки струму живлення. За замовчуванням слід обирати найнижчу швидкість наростання фронту, достатню для робочої частоти лінії.

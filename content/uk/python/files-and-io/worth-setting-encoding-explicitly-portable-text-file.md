## Short answer

**Типове кодування залежить від ОС: `locale.getencoding()` повертає, наприклад, `cp1252` на Windows або `utf-8` на більшості Linux-систем.**[^py314-library-io] Файл, записаний без явного `encoding`, може стати нечитабельним на іншій машині. Починаючи з Python 3.15, UTF-8 Mode стане типовим, але в 3.14 і раніше явне `encoding="utf-8"` – єдиний спосіб гарантувати однакове читання/запис на всіх платформах.

## Short answer

**У binary mode `seek()` і `tell()` працюють із byte offsets; у text mode `tell()` повертає «opaque cookie», а `seek()` підтримує лише `seek(0)` і відновлення з `tell()`.**[^py314-library-io] У text mode з кодуванням на кшталт UTF-8 один символ може займати 1–4 байти, тому позиція в байтах не збігається з позицією в символах. CPython використовує внутрішній алгоритм для відновлення позиції, тому довільні числові offset у text mode не підтримуються і можуть дати undefined behavior.

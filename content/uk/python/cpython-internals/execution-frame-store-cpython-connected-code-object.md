## Short answer

**Frame object зберігає посилання на code object (`f_code`), словники globals (`f_globals`) і locals (`f_locals`), та вказівник на попередній frame (`f_back`), формуючи таким чином linked list – call stack.**[^py314-library-dis] Кожен виклик функції або методу створює новий frame. Через `f_lasti` frame фіксує поточну позицію виконання всередині bytecode. Frame також доступний у traceback objects та trace functions.

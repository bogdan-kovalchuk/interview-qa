## Short answer

Напівсуматор додає два двійкові біти A і B без урахування вхідного переносу. Біт суми S формується елементом XOR за рівнянням `S = A ^ B`, даючи 1 лише за різних значень входів. Біт вихідного переносу C формується елементом AND за рівнянням `C = A & B`, приймаючи значення 1 лише тоді, коли обидва входи дорівнюють 1.[^floyd-digital-fundamentals]

## Detailed explanation

### Призначення та таблиця істинності
Напівсуматор (Half Adder, HA) – це найпростіший базовий комбінаційний вузол двійкової арифметики, призначений для додавання двох однорозрядних чисел `A` та `B`. Результат арифметичного додавання може набувати значень 0, 1 або 2 (що в двійковому записі становить `10_2`), тому для його фіксації потрібно два вихідні розряди: молодший біт суми `S` (Sum) та старший біт вихідного переносу `C` (Carry).[^floyd-digital-fundamentals]

Таблиця істинності напівсуматора має такий вигляд:[^tocci-digital-systems]
- `A = 0, B = 0`: `S = 0, C = 0` (арифметична сума 0)
- `A = 0, B = 1`: `S = 1, C = 0` (арифметична сума 1)
- `A = 1, B = 0`: `S = 1, C = 0` (арифметична сума 1)
- `A = 1, B = 1`: `S = 0, C = 1` (арифметична сума 2, тобто `10_2`)

### Логічні рівняння та вентильна структура
З аналізу таблиці істинності безпосередньо випливають функції кожного виходу:[^floyd-digital-fundamentals]
1. Формування біта суми `S`:
   Вихід `S` дорівнює `1`, коли входи відрізняються один від одного (один із них дорівнює 1, а інший – 0). Це відповідає операції «виключне АБО» (XOR, додавання за модулем 2):
   `S = A ^ B = (~A & B) | (A & ~B)`
   Вентиль XOR безпосередньо генерує двійкову суму поточного розряду без урахування переносу.
2. Формування біта переносу `C`:
   Вихід `C` стає рівним `1` лише за умови, коли обидва входи одночасно дорівнюють `1`. Це повністю відповідає логічній операції «І» (AND):
   `C = A & B`
   Вентиль AND фіксує арифметичне переповнення розряду (`1 + 1 = 2`), формуючи сигнал переносу до наступного, старшого розряду.

Таким чином, повна схема напівсуматора реалізується всього на двох вентилях: одному двовходовому XOR та одному двовходовому AND.[^tocci-digital-systems]

### Схемотехнічні нюанси та затримки поширення
У мікроелектронній технології КМОН вентиль AND будується як послідовне з’єднання вентиля NAND (4 транзистори) та інвертора NOT (2 транзистори), потребуючи 6 транзисторів. Вентиль XOR є складнішим і типово вимагає від 8 до 12 транзисторів при реалізації на базі передавальних ключів (transmission gates).[^tocci-digital-systems]
Через це затримка поширення сигналу від входів до виходу суми `t_pd(XOR)` зазвичай перевищує затримку формування сигналу переносу `t_pd(AND)`. Ця часова різниця враховується інженерами при моделюванні гонок сигналів (race conditions) та часових провалів (glitches) у комбінаційних схемах.

### Обмеження напівсуматора
Назва «напівсуматор» обумовлена тим, що схема може додавати лише два біти і не має третього входу для врахування вхідного переносу `C_in`, що прийшов від попереднього (молодшого) розряду.[^floyd-digital-fundamentals] Через це напівсуматор не можна використовувати для послідовного нарощування розрядності багатобітових суматорів, окрім наймолодшого розряду (LSB). Для всіх інших розрядів (від 1 до `n-1`) застосовують повний суматор (Full Adder).

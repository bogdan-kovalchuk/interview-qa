## Short answer

Віднімання числа `A - B` математично еквівалентне додаванню протилежного значення `A + (-B)`. Оскільки від’ємне число формується як `~B + 1`, процесор використовує той самий апаратний суматор для обох дій. Будь-який вихідний біт переносу за межі розрядної сітки під час віднімання в межах фіксованої розрядності відкидається.[^floyd-digital-fundamentals]

## Detailed explanation

### Математична еквівалентність віднімання та додавання
В арифметиці процесорів і цифрових обчислювачів будь-які обчислення над числами фіксованої розрядності `n` відбуваються в кільці лишків за модулем `2^n`. Операцію віднімання двох чисел `A - B` можна представити як додавання від’ємного числа: `A + (-B) (mod 2^n)`.[^floyd-digital-fundamentals]

У системі з доповненням до двох від’ємне число `-B` визначається як різниця між модулем системи `2^n` та числом `B`:[^aac-subtraction-twos-complement]
`-B = 2^n - B = (2^n - 1 - B) + 1 = ~B + 1`
де `~B` – порозрядне логічне заперечення (NOT) операнда `B` (доповнення до одиниці).

Підставляючи цей вираз у операцію віднімання, отримуємо:
`A - B = A + ~B + 1 (mod 2^n)`

Це фундаментальне співвідношення означає, що для виконання операції віднімання над двійковими числами не потрібно проєктувати окремий складний блок віднімання. Достатньо виконати порозрядну інверсію бітів від’ємника `B`, подати їх на входи стандартного суматора разом із зменшуваним `A` та подати логічну `1` на вхід молодшого вхідного переносу `C_in` суматора.[^floyd-digital-fundamentals]

### Схемотехнічна реалізація: суматор-віднімач (Adder/Subtractor)
В арифметико-логічних пристроях (АЛП) на базі двійкового суматора реалізується універсальний блок суматора-віднімача за допомогою керованих інверторів на елементах «виключне АБО» (XOR):[^floyd-digital-fundamentals]
- Керуючий сигнал режиму `SUB` підключається до одного з входів кожного вентиля XOR розрядів операнда `B`, а також до входу вхідного переносу молодшого розряду суматора `C_in`.
- Режим додавання (`SUB = 0`):
  Оскільки `B_i ^ 0 = B_i`, операнд `B` надходить на входи суматора без змін. На вхід переносу подається `C_in = 0`. Суматор обчислює `S = A + B + 0 = A + B`.
- Режим віднімання (`SUB = 1`):
  Оскільки `B_i ^ 1 = ~B_i`, вентилі XOR автоматично інвертують кожен біт операнда `B`. Одночасно на вхід `C_in` подається `1`. Суматор обчислює `S = A + ~B + 1 = A - B`.

### Поведінка вихідного переносу та переповнення
Під час виконання операції віднімання через додавання утворюються два важливі статусні біти:[^aac-subtraction-twos-complement]
1. Вихідний перенос (Carry-Out, `C_out`):
   При відніманні `A - B` перенос із старшого розряду суматора формується завжди, коли `A >= B` (у беззнаковому сенсі). Оскільки результат поміщається в `n` розрядів, біт переносу `2^n` виходить за межі сітки і для самого значення результату просто відкидається. Водночас у беззнаковій арифметиці `C_out = 1` означає відсутність запозичення (Borrow = 0), а `C_out = 0` сигналізує про запозичення (Borrow = 1).
2. Арифметичне переповнення знакових чисел (Overflow Flag, `V` або `OF`):
   Переповнення виникає, якщо результат виходить за межі діапазону `[-2^(n-1), 2^(n-1) - 1]`. Воно визначається апаратно за допомогою схеми XOR між переносом у знаковий розряд `C_(n-1)` та вихідним переносом `C_out`:
   `V = C_(n-1) ^ C_out`
   Якщо `V = 1`, результат є хибним через нестачу розрядної сітки.[^floyd-digital-fundamentals]

## Short answer

Булева змінна та її інверсія завжди мають взаємно протилежні значення 0 і 1. Оскільки логічне І (AND) з нулем завжди дає нуль, кон’юнкція X * /X = 0. Оскільки логічне АБО (OR) з одиницею завжди дає одиницю, диз’юнкція X + /X = 1. Ці тотожності є фундаментом мінімізації цифрових схем, дозволяючи факторизувати вирази та усувати надлишкові логічні вентилі.[^floyd-digital-fundamentals]

## Detailed explanation

### Теоретичне підґрунтя тотожностей комплементарності

У класичній двійковій булевій алгебрі будь-яка змінна `X` належить множині `{0, 1}`. Операція комплементарності (NOT, інверсія `/X` або `!X`) перетворює 0 на 1, а 1 на 0. Відповідно, пара `(X, /X)` у будь-який момент часу містить одне нульове та одне одиничне значення:[^floyd-digital-fundamentals]
- Якщо `X = 0`, то `/X = 1`. Тоді `0 * 1 = 0` та `0 + 1 = 1`.
- Якщо `X = 1`, то `/X = 0`. Тоді `1 * 0 = 0` та `1 + 0 = 1`.

Звідси випливають дві фундаментальні аксіоми комплементарності:[^mano-digital-design]
1. `X * /X = 0` – Закон несуперечності (Law of Contradiction): висловлювання не може бути одночасно істинним і хибним. Кон’юнкція будь-якої змінної з її власним запереченням завжди дає тотожний логічний нуль.
2. `X + /X = 1` – Закон виключеного третього (Law of Excluded Middle): висловлювання є або істинним, або хибним, третього не дано. Диз’юнкція будь-якої змінної з її власним запереченням завжди дає тотожну логічну одиницю.

### Механізм мінімізації логічних виразів

Ці дві тотожності лежать в основі аналітичного спрощення булевих функцій у формах суми добутків (SOP – Sum of Products) та добутку сум (POS – Product of Sums):[^aac-boolean-rules]

1. Факторизація та усунення надлишкових змінних:
   Розглянемо вираз `F = A * B + A * /B`.
   Використовуючи дистрибутивний закон (винесення спільного множника за дужки):
   `F = A * (B + /B)`
   Підставляючи тотожність комплементу `B + /B = 1`:
   `F = A * 1 = A`
   Завдяки тотожності зникла змінна `B`, що на практиці усуває один інвертор, один двовходовий вентиль AND та зменшує кількість входів вихідного вентиля OR.[^floyd-digital-fundamentals]

2. Анігіляція суперечливих кон’юнкцій:
   Якщо в результаті розкриття дужок утворюється добуток, що містить одночасно пряму та інверсну змінні, він миттєво обнуляється:
   `F = A * B * /A * C + D = (A * /A) * B * C + D = 0 * B * C + D = 0 + D = D`

3. Теорема консенсусу (Consensus Theorem):
   Тотожність `A * B + /A * C + B * C = A * B + /A * C` доводиться через домноження надлишкового доданка `B * C` на одиницю у вигляді `(A + /A)`:
   `B * C = B * C * (A + /A) = A * B * C + /A * B * C`
   Далі отримані доданки поглинаються основними термами за рахунок правила поглинання `X + X * Y = X`.[^mano-digital-design]

### Алгоритмічне значення: карти Карно та метод Квайна-Маккласкі

У графічному методі мінімізації (картах Карно) склеювання суміжних клітинок у прямокутні групи розміром 2, 4, 8 або 16 елементів є прямою геометричною реалізацією тотожності `X + /X = 1`.[^floyd-digital-fundamentals] Два сусідні мінтерми, які відрізняються лише значенням однієї змінної (код Грея), об’єднуються саме тому, що `P * X + P * /X = P * (X + /X) = P`. Аналогічно, комп’ютерні алгоритми синтезу логіки (наприклад, Quine-McCluskey та Espresso в САПР Quartus чи Vivado) використовують це правило для знаходження первинних імплікант.

### Інженерний вплив на апаратуру

Оптимізація на основі тотожностей комплементарності забезпечує наступні переваги для цифрових мікросхем:[^mano-digital-design]
- Зменшення кількості логічних вентилів (Gate Count) і площі кремнієвого кристала в ASIC та зменшення числа зайнятих LUT (Look-Up Table) у FPGA;
- Зменшення затримки поширення сигналу (Propagation Delay) через зменшення глибини логічних рівнів, що підвищує граничну тактову частоту схеми;
- Зниження динамічної потужності споживання, яка прямо пропорційна кількості комутованих вузлів та їхній паразитній ємності (`P_dyn = sum C * V^2 * f`).

## Short answer

Вентиль AND підпорядковується законам булевого множення X * 1 = X та X * 0 = 0. Якщо подати сигнал даних на один вхід, а сигнал дозволу (ENABLE) на інший, за рівня ENABLE = 1 сигнал проходить на вихід без змін. Подання рівня ENABLE = 0 блокує вентиль, утримуючи на виході постійний логічний 0 незалежно від вхідного сигналу.[^floyd-digital-fundamentals]

## Detailed explanation

### Принцип роботи вентиля AND як ключового елемента

Вентиль логічного множення І (AND) реалізує функцію кон’юнкції двох вхідних сигналів: інформаційного сигналу даних `DATA` та керуючого сигналу дозволу `ENABLE` (стробу або стробуючого імпульсу):[^floyd-digital-fundamentals]
`OUTPUT = DATA * ENABLE`

Поведінка схеми визначається базовими законами булевої алгебри для констант 1 та 0:[^aac-and-gate]
1. Стан дозволу (Pass / Enable, коли `ENABLE = 1`):
   `OUTPUT = DATA * 1 = DATA`
   Якщо `DATA = 0`, то `OUTPUT = 0 * 1 = 0`.
   Якщо `DATA = 1`, то `OUTPUT = 1 * 1 = 1`.
   Ключ відкрито: сигнал `DATA` передається на вихід без інверсії з мінімальною затримкою, що дорівнює власній затримці поширення вентиля `t_pd` (для логіки HC, наприклад SN74HC08, близько 7–10 нс при напрузі 5 В).[^ti-sn74hc08-datasheet]
2. Стан блокування (Inhibit / Disable, коли `ENABLE = 0`):
   `OUTPUT = DATA * 0 = 0`
   Ключ закрито: вихід вентиля примусово фіксується в стані стабільного логічного нуля незалежно від того, які значення, імпульси чи перешкоди з’являються на інформаційному вході `DATA`.

### Порівняння з іншими логічними вентилями у ролі стробів

Різні типи базових логічних елементів забезпечують різні режими стробування сигналів:[^floyd-digital-fundamentals]
- Вентиль І-НЕ (NAND): при `ENABLE = 1` працює як інвертор сигналу (`OUTPUT = !DATA`), а при `ENABLE = 0` блокує проходження, фіксуючи на виході постійний високий рівень (`OUTPUT = 1`).
- Вентиль АБО (OR): сигнал дозволу активний низьким рівнем (`ENABLE = 0`), при якому `OUTPUT = DATA + 0 = DATA`. При `ENABLE = 1` вихід примусово блокується на рівні 1 (`OUTPUT = DATA + 1 = 1`).
- Вентиль Виключне АБО (XOR): служить керованим інвертором. При `CONTROL = 0` пропускає сигнал без змін (`OUTPUT = DATA`), а при `CONTROL = 1` повністю інвертує його (`OUTPUT = !DATA`).

### Практичне застосування в цифрових системах

1. Стробування тактового сигналу (Clock Gating):
   У сучасних мікропроцесорах та системах на кристалі (SoC) вентилі AND використовуються для вимкнення тактування невикористовуваних функціональних блоків (наприклад, блоку плаваючої коми або апаратного шифратора). Оскільки динамічна потужність КМОН-схем пропорційна частоті перемикання (`P_dyn = C * V^2 * f`), блокування тактових імпульсів на вході AND зменшує споживання енергії практично до нуля.[^ti-sn74hc08-datasheet]
2. Цифрові частотоміри та вимірювачі часових інтервалів:
   Вхідний сигнал еталонного генератора подається через вентиль AND на лічильник імпульсів, а на вхід `ENABLE` подається строб каліброваної тривалості (наприклад, рівно 1 секунда). Лічильник фіксує кількість періодів, що пройшли за час відкритого ключа, що прямо відповідає частоті сигналу.[^floyd-digital-fundamentals]
3. Мультиплексування та маршрутизація сигналів:
   Комбінація кількох вентилів AND, виходи яких об’єднані через вентиль OR, утворює базовий цифровий мультиплексор даних (MUX), де сигнали селектора відкривають проходження лише одного з багатьох вхідних каналів.

### Проблема паразитних сплесків (Glitches) та їх усунення

Критичною проблемою простого стробування тактових сигналів через вентиль AND є виникнення паразитних імпульсів (glitches або runt pulses):[^floyd-digital-fundamentals]
- Якщо сигнал `ENABLE` перемикається в момент, коли тактовий сигнал `CLK` перебуває на високому рівні, на виході AND з’являється обірваний короткий імпульс ненормативної тривалості.
- Такий імпульс порушує часові вимоги тригерів (setup/hold time) і спричиняє непередбачувані збої системи.
- Схемотехнічне вирішення: використання інтегрованих комірок стробування такту (ICG – Integrated Clock Gating Cell). У таких комірках сигнал `ENABLE` перед подачею на вентиль AND синхронізується внутрішнім тригером-засувкою (latch), який замикається по спадному фронту `CLK`. Це гарантує, що стан дозволу змінюється виключно тоді, коли тактовий сигнал перебуває на низькому рівні, повністю виключаючи появу паразитного сплеску на виході.

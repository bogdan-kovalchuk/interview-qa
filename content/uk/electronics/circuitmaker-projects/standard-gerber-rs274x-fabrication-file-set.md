## Short answer

Комплект містить файли верхнього й нижнього шарів міді, паяльної маски та маркування шовкодруку. Додатково додаються контур плати на механічному шарі та файл координат свердління отворів NC Drill. Без будь-якого з цих файлів завод не зможе виготовити або обробити друковану плату.[^udemy-electronics-course]

## Short answer

Виробникові голої плати потрібен пакет Gerber-файлів (RS-274X або Gerber X2) для кожного фізичного шару (мідь, маска, шовкографія, контур плати), файли свердління Excellon (PTH і NPTH) та нетлист IPC-D-356 для електричного тестування. Для автоматизованого монтажу (PCBA) додатково передають специфікацію компонентів (BOM), файл координат розстановки Pick-and-Place (Centroid) і складальні креслення.[^ipc-2581]

## Detailed explanation

Підготовка повного та коректного пакета конструкторської документації є запорукою успішного безпомилкового виробництва голої друкованої плати (Bare Board Fabrication) та автоматизованого монтажу електронних компонентів (PCBA Assembly).

### Пакет файлів для виготовлення друкованої плати (Bare Board Fabrication)

Виробник друкованої плати використовує комплекс файлів, що описують пошарову геометрію та механічну обробку:

1. **Файли шарів у форматі Gerber (RS-274X або сучасний розширений Gerber X2)** [^ucamco-gerber-spec]:
   - Векторні файли у форматі ASCII, де кожен файл відповідає одному технологічному шару:
     - **Шари міді (Copper Layers)**: Top Copper, Bottom Copper, Inner 1, Inner 2 тощо. Описують геометрію провідників, полігонів і контактних площадок.
     - **Шари паяльної маски (Solder Mask Top/Bottom)**: визначають вікна в захисному полімерному покритті (зеленому, чорному тощо), де мідні площадки залишаються відкритими для подальшого паяння.
     - **Шари шовкографії (Silkscreen / Legend Top/Bottom)**: графічні зображення позиційних позначень (R1, C1), полярності діодів, міток першого виводу мікросхем і логотипів, що наносяться стійкою фарбою.
     - **Механічний шар контуру плати (Board Outline / Edge Cuts)**: задає точні зовнішні габарити плати, радіуси заокруглень, внутрішні вікна, фрезеровані пази та лінії надрізів для розділення групової панелі (V-score).
2. **Файли свердління NC Drill (Excellon або Gerber X2)** [^ucamco-gerber-spec]:
   - Текстові файли з координатами та діаметрами отворів для свердлильних верстатів із ЧПК:
     - **Металізовані отвори (Plated Through-Hole, PTH)**: перехідні отвори та отвори під вивідні компоненти, внутрішня поверхня яких покривається міддю під час гальванічного процесу.
     - **Неметалізовані отвори (Non-Plated Through-Hole, NPTH)**: отвори для кріплення, напрямні або оптичні репери, які свердляться після металізації або захищаються сухим фоторезистом.
     - **Таблиця інструментів (Tool Rack / Tool Table)**: містить відповідність номерів інструментів (T01, T02...) фізичним діаметрам свердел.
3. **Нетлист електричного тестування (IPC-D-356 / IPC-D-356A)** [^ipc-d-356a]:
   - Текстовий опис з’єднань між усіма контактними площадками плати. Завод використовує його для автоматизованого тестування «літаючими щупами» (flying probe) або стендом із полем контактів («ложе цвяхів»), перевіряючи відсутність обривів (opens) і коротких замикань (shorts) перед відвантаженням.
4. **Виробнича специфікація (Fabrication Notes / Readme)**:
   - Текстовий документ або креслення, що визначає загальну товщину плати (наприклад, 1.6 мм +- 10%), матеріал основи (FR-4 Standard, High-Tg 170°C, алюміній), вагу міді (1 oz, 2 oz), фінішне покриття (HASL, ENIG, OSP, Immersion Silver), колір маски, колір маркування та клас виготовлення за IPC-6012.

### Пакет файлів для автоматизованого монтажу компонентів (PCBA Assembly)

Монтажне підприємство встановлює та паяє компоненти за допомогою спеціалізованого пакета даних:

1. **Специфікація компонентів (Bill of Materials, BOM)** [^ipc-2581]:
   - Таблиця (зазвичай Excel або CSV), що містить:
     - Позиційне позначення (Reference Designator: C1, R2, U3);
     - Номінал і параметри (Value / Description: 10 uF 25V X7R, 0603);
     - Тип корпусу (Footprint: 0603, SOIC-8, QFN-32);
     - Повний код виробника (Manufacturer Part Number, MPN);
     - Виробника компонента;
     - Кількість деталей та вказівку на невстановлювані компоненти (DNP / Do Not Populate).
2. **Файл координат для автоматичного встановлення (Pick-and-Place / Centroid / CPL)** [^ipc-7351b]:
   - Текстовий файл, який зчитує робот-маніпулятор SMT-лінії:
     - Позиційне позначення компонента;
     - Координати геометричного центру (X, Y в міліметрах або мілах) відносно початку координат або оптичних реперних знаків (Fiducial markers);
     - Кут повороту (Rotation: від 0° до 359.9° згідно зі стандартом орієнтації IPC-7351);
     - Сторона плати (Top або Bottom).
3. **Шари трафарету паяльної пасти (Solder Paste / Stencil Top/Bottom)** [^ipc-7351b]:
   - Gerber-файли з отворами (апертурами), за якими лазером вирізають металевий трафарет із нержавіючої сталі для нанесення паяльної пасти на SMD-площадки.
4. **Складальні креслення (Assembly Drawings)**:
   - PDF-файли з графічним розташуванням компонентів, маркуванням перших виводів мікросхем, орієнтацією полярних конденсаторів, діодів, транзисторів, роз’ємів та інструкціями щодо ручного допаювання нестандартних деталей.

### Сучасні комплексні формати передачі даних

Щоб усунути ризик розсинхронізації між окремими файлами Gerber, свердління, BOM і Centroid, електронна промисловість розробила єдині цифрові контейнери – **IPC-2581** та **ODB++** [^ipc-2581]. Вони містять усю геометричну інформацію шарів, стек матеріалів, нетлист, специфікацію BOM і координати компонентів в єдиній структурованій цифровій моделі (XML або ієрархічний архів), що повністю виключає помилки ручної інтерпретації файлів на заводі.

## Short answer

JK-тригер усуває заборонений стан SR-тригера: при J = 0, K = 0 стан зберігається, при 10 – встановлюється 1, при 01 – скидається в 0. Комбінація J = 1, K = 1 переводить тригер у режим лічильного перемикання (toggle), коли кожен тактовий імпульс інвертує вихід на протилежний. Завдяки цьому JK-тригер є ідеальним дільником частоти на 2 і базовою коміркою двійкових лічильників.[^floyd-digital-fundamentals]

## Detailed explanation

Універсальний тактований JK-тригер (JK flip-flop) був розроблений для повного усунення проблеми невизначеності й забороненого стану `S = 1, R = 1`, притаманного класичним SR-тригерам.[^floyd-digital-fundamentals] Назва входу `J` історично асоціюється з встановленням (Set), а входу `K` – зі скиданням (Clear/Reset).

### Внутрішня схемотехніка та усунення невизначеності

Вирішення проблеми забороненого стану досягається введенням внутрішнього перехресного зворотного зв’язку з виходів схеми `Q` та `~Q` на вхідні логічні вентилі керування (AND або NAND):[^tocci-digital-systems]
- Внутрішній сигнал встановлення формується як `S_int = J * ~Q`.
- Внутрішній сигнал скидання формується як `R_int = K * Q`.

Завдяки такій комутації стан виходу автоматично селектує активний вхід:
- Якщо тригер скинутий (`Q = 0`, `~Q = 1`), вхід скидання `K` повністю заблокований нулем (`R_int = K * 0 = 0`), а вхід встановлення `J` відкритий (`S_int = J * 1 = J`). Схема може лише перемкнутися в одиницю.
- Якщо тригер встановлений (`Q = 1`, `~Q = 0`), заблокований вхід встановлення `J` (`S_int = J * 0 = 0`), а вхід `K` розблокований (`R_int = K * 1 = K`). Схема може лише скинутися в нуль.
- Одночасне збудження обох внутрішніх ліній `S_int` та `R_int` фізично унеможливлене, оскільки за будь-якого стану виходів одна з ліній обов’язково блокується логічним нулем.

### Таблиця істинності та характеристичне рівняння

Поведінка JK-тригера за активним перепадом тактового сигналу `CLK` описується такою таблицею переходів:[^floyd-digital-fundamentals]

| J | K | Поточний стан Q(t) | Наступний стан Q(t+1) | Режим роботи |
|---|---|---|---|---|
| 0 | 0 | 0 / 1 | 0 / 1 (без змін) | Зберігання стану (Hold / Memory) |
| 0 | 1 | 0 / 1 | 0 | Синхронне скидання (Reset / Clear) |
| 1 | 0 | 0 / 1 | 1 | Синхронне встановлення (Set) |
| 1 | 1 | 0 / 1 | 1 / 0 (інверсія) | Лічильний режим (Toggle) |

Аналітично наступний стан описується характеристичним рівнянням булевої алгебри:[^tocci-digital-systems]

`Q_next = J * ~Q + ~K * Q`

Це рівняння безпосередньо демонструє:
- при `J = 0, K = 0`: `Q_next = 0 * ~Q + 1 * Q = Q` (збереження);
- при `J = 0, K = 1`: `Q_next = 0 * ~Q + 0 * Q = 0` (скидання);
- при `J = 1, K = 0`: `Q_next = 1 * ~Q + 1 * Q = ~Q + Q = 1` (встановлення);
- при `J = 1, K = 1`: `Q_next = 1 * ~Q + 0 * Q = ~Q` (інверсія).

### Чому режим J = 1, K = 1 є фундаментальним для лічильників

Комбінація `J = 1, K = 1` перетворює JK-тригер на так званий T-тригер (Toggle flip-flop). Цей режим є основою всієї цифрової лічильної техніки з таких причин:[^ti-sn74ls112a-datasheet]

1. **Ідеальний дільник частоти на 2:**
   Оскільки кожен активний тактовий перепад інвертує вихід тригера, для завершення одного повного періоду коливань вихідного сигналу `Q` (перехід `0 -> 1 -> 0`) потрібно рівно два тактових імпульси на вході `CLK`. Вихідна частота становить строго `f_out = f_clk / 2`. При цьому вихідний сигнал має ідеальну шпаруватість 50% (симетричний меандр) незалежно від шпаруватості вхідного тактового сигналу.

2. **Побудова асинхронних (пульсуючих) лічильників (Ripple Counters):**
   При каскадуванні, коли прямий або інверсний вихід попереднього JK-тригера підключається до тактового входу `CLK` наступного, утворюється асинхронний двійковий лічильник. Кожен наступний розряд ділить частоту ще у 2 рази (`f_clk / 2, f_clk / 4, f_clk / 8, ...`), утворюючи послідовність двійкового рахунку.

3. **Синхронні двійкові лічильники з керованим перемиканням:**
   У синхронних лічильниках усі тактові входи `CLK` об’єднані, а лічильний режим вмикається вибірково. Якщо об’єднати входи `J` та `K` кожного тригера в спільну лінію керування `T` (`J = K = T`), то при `T = 1` розряд перемикається, а при `T = 0` – зберігає поточне значення. Подаючи на вхід `T` розряду `i` результат кон’юнкції виходів усіх молодших розрядів (`T_i = Q_0 * Q_1 * ... * Q_(i-1)`), реалізують високошвидкісні синхронні лічильники прямого двійкового рахунку.[^floyd-digital-fundamentals]

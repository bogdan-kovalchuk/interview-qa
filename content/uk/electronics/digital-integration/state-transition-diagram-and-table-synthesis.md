## Short answer

Синтез починається зі складання графа перехідних станів, де вузли задають стійкі стани, а спрямовані дуги позначають умови переходів від зовнішніх сигналів. Далі стани кодують двійковими векторами (наприклад, двійковим кодом або кодом One-Hot) та формують зведену таблицю переходових функцій. На основі таблиці для кожного тригера записують логічне рівняння наступного стану відносно поточних змінних.[^mano-digital-design]

## Detailed explanation

Формальний синтез синхронного кінцевого автомата (FSM) являє собою строго алгоритмізований інженерний процес перетворення словесного технічного завдання на функціонування керуючого пристрою в принципову логічну схему на рівні тригерів і логічних вентилів.[^mano-digital-design]

Синтез виконується за класичною інженерною послідовністю з шести взаємопов’язаних етапів:[^floyd-digital-fundamentals]

### 1. Побудова графа та діаграми станів (State Transition Diagram)

Словесний опис алгоритму роботи формалізується у вигляді орієнтованого графа станів:
- Кожна вершина графа позначає унікальний внутрішній стан автомата (`S_0, S_1, ..., S_(N-1)`).
- Спрямовані стрілки (дуги) показують можливі переходи між станами під дією активного перепаду тактового сигналу.
- **Нотація:** для автомата Мура вихідні сигнали записують безпосередньо у вершині станів (`S_i / Output`), а дуги маркують виключно значеннями вхідних змінних (`Input`). Для автомата Мілі умови переходів та сформовані виходи маркують на самих дугах у форматі `Input / Output`.

### 2. Мінімізація станів (State Reduction)

Метою мінімізації є скорочення надлишкових станів для спрощення схеми без зміни зовнішньої поведінки «вхід-вихід»:[^tocci-digital-systems]
- Два стани називаються еквівалентними, якщо за будь-якої можливої вхідної послідовності вони генерують абсолютно ідентичні вихідні сигнали та переходять в однакові (або також еквівалентні) стани.
- Виявлення еквівалентних станів здійснюється побудовою **таблиці включень (implication table)** або методом розбиття станів на класи еквівалентності.
- Усі еквівалентні стани зливаються в один, що зменшує загальну кількість станів `N` і нерідко дозволяє зменшити необхідне число тригерів пам’яті.

### 3. Кодування станів (State Assignment)

Кожному абстрактному стану `S_i` ставиться у відповідність унікальний двійковий вектор розрядністю `k`. Вибір стилю кодування залежить від цільової апаратної платформи:[^mano-digital-design]
- **Двійкове щільне кодування (Binary encoding):** потребує мінімальної кількості тригерів: `k = ceil(log2(N))`. Оптимально для дискретних мікросхем ТТЛ/КМОН, проте може ускладнювати комбінаційну логіку переходу.
- **Кодування Грея (Gray code):** коди сусідніх станів графа відрізняються лише одним бітом. Зменшує кількість динамічних перемикань тригерів і знижує споживання енергії.
- **Унітарне кодування (One-Hot encoding):** виділяє окремий тригер для кожного стану (`k = N`). У кожен момент часу лише один тригер має логічну `1`, а решта – `0`. Це суттєво спрощує рівняння комбінаційної логіки наступного стану й мінімізує затримку поширення, що робить One-Hot домінантним методом для FPGA-архітектур із надлишком тригерів і 4/6-входовими LUT.

### 4. Складання таблиці переходів та збуджень (State Transition & Excitation Table)

На основі закодованих станів формується розширена таблиця істинності, яка містить стовпці:
- Поточний стан регістра: `Q_k(t) ... Q_0(t)`;
- Зовнішні вхідні сигнали: `X_m ... X_0`;
- Наступний стан: `Q_k(t+1) ... Q_0(t+1)`;
- Вихідні сигнали: `Y_p ... Y_0`;
- Сигнали збудження входів тригерів (наприклад, `D_i` для D-тригерів або `J_i, K_i` для JK-тригерів).

Для визначення сигналів збудження використовують матриці збудження конкретного типу тригера:[^floyd-digital-fundamentals]
- Для D-тригера: керуючий сигнал тривіально повторює наступний стан: `D_i = Q_i(t+1)`.
- Для JK-тригера використовують перевагу байдужих станів (`X` – Don't care):
  - перехід `0 -> 0`: `J = 0, K = X`;
  - перехід `0 -> 1`: `J = 1, K = X`;
  - перехід `1 -> 0`: `J = X, K = 1`;
  - перехід `1 -> 1`: `J = X, K = 0`.

### 5. Логічна мінімізація функцій збудження та виходів

Для кожного входу збудження тригерів (`D_i` або `J_i, K_i`) та для кожного вихідного сигналу `Y_j` будують карту Карно або викликають алгоритм мінімізації Куайна-Маккласкі:[^tocci-digital-systems]
- Заповнюють клітинки одиницями, нулями та невизначеними станами `X`.
- Невикористовувані кодові комбінації (якщо `2^k > N`) також позначаються як `X`, що дозволяє максимально укрупнити групи склеювання та отримати мінімальні вирази у формі суми добутків (SOP).

### 6. Схемотехнічна реалізація та аналіз на самовідновлення (Self-Recovery)

Отримані булеві рівняння транслюються в схему логічних вентилів (AND, OR, NOT, NAND), підключених до інформаційних входів регістра стану.

На завершальному етапі обов’язково виконують **аналіз самовідновлення**:[^mano-digital-design] перевіряють поведінку схеми для невикористовуваних кодових станів. Якщо внаслідок електромагнітної завади автомат випадково опиниться в невикористаному стані, логіка наступного стану повинна гарантовано за фіксовану кількість тактів перевести автомат у коректний робочий стан (зазвичай у стан скидання `S_0`), запобігаючи нескінченному апаратному зависанню (lockup state).

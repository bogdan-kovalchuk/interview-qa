## Short answer

Вибір режиму роботи 74x181 визначається керуючим входом M: коли M = 1 (HIGH), блок виконує одну з 16 побітових логічних функцій без участі внутрішнього перенесення. Коли M = 0 (LOW), схема виконує одну з 16 арифметичних операцій з урахуванням перенесення. Конкретна операція всередині обраного режиму кодується 4-бітним словом на селекторних входах S3–S0.[^ti-sn74ls181-datasheet]

## Detailed explanation

Мікросхема 74x181 (74181, 74LS181, 74S181) – це класичний 4-бітний комбінаційний арифметико-логічний пристрій (АЛП) у 24-вивідному корпусі DIP, який здатен виконувати 16 побітових логічних та 16 арифметичних операцій над двома 4-розрядними операндами A (входи `A0..A3`) та B (входи `B0..B3`).[^ti-sn74ls181-datasheet]

### Керування режимом за допомогою входу M

Головним перемикачем функціонального призначення є вхід керування режимом `M` (Mode Control):[^floyd-digital-fundamentals]
- **Логічний режим (`M = 1` / HIGH)**: сигнал високого рівня примусово блокує внутрішній ланцюг прискореного міжрозрядного перенесення (Carry Lookahead). Кожен із чотирьох розрядів схеми функціонує як незалежний однобітний функціональний генератор булевих функцій. Стан входу вхідного перенесення `Cn` повністю ігнорується і не впливає на вихідний результат `F0..F3`. Вихід групового генератора перенесення `\bar{G}` утримується на високому рівні, а `\bar{P}` відтворює інверсію внутрішніх функцій.
- **Арифметичний режим (`M = 0` / LOW)**: логічний нуль на вході `M` деблокує внутрішні вентилі генерації та розповсюдження міжрозрядного перенесення. Схема перетворюється на 4-розрядний паралельний суматор/віднімач із повним урахуванням вхідного перенесення `Cn` та формуванням вихідного міжмікросхемного перенесення `Cn+4`, а також виходів для блоку групового переносу `\bar{P}` (Propagate) і `\bar{G}` (Generate).

### Селекторні лінії S3–S0 та генерація функцій

Конкретний тип операції в обраному режимі задається 4-розрядним двійковим кодом на селекторних входах `S3`, `S2`, `S1`, `S0`:[^ti-sn74ls181-datasheet]
- Внутрішній перший ярус логіки містить вентилі AND-OR-INVERT, які формують проміжні терми розповсюдження `P_i` та генерації `G_i` як функції від `A_i`, `B_i` та керуючих ліній `S0..S3`.
- При `M = 1` ці терми безпосередньо комбінуються для отримання всіх 16 можливих булевих операцій двох змінних: наприклад, при `S = 0000` вихід `F = NOT A`; при `S = 0110` вихід `F = A XOR B`; при `S = 1011` вихід `F = A AND B`; при `S = 1110` вихід `F = A OR B`.
- При `M = 0` ті самі комбінації `S3..S0` визначають математичну формулу додавання або віднімання операндів із врахуванням перенесення. Наприклад, для активних високих рівнів код `S = 1001` відповідає додаванню `F = A PLUS B`, код `S = 0110` відповідає відніманню `F = A MINUS B MINUS 1`, код `S = 0000` виконує декремент `F = A MINUS 1`, а код `S = 1111` виконує просту передачу `F = A`.[^mano-logic-computer-design]

### Системне використання та каскадування

Оскільки 74x181 є суто комбінаційним пристроєм без внутрішніх регістрів синхронізації, перемикання ліній `M` та `S3..S0` безпосередньо переналаштовує шлях поширення логічних сигналів між входами операндів та вихідною шиною `F`.[^mano-logic-computer-design] При побудові процесорних трактів ширшої розрядності (8, 16 або 32 біти) лінії `M` та `S0..S3` об’єднуються паралельно для всіх мікросхем АЛП і підключаються до виходів декодера команд або регістра мікрокоду пристрою керування (Control Unit).

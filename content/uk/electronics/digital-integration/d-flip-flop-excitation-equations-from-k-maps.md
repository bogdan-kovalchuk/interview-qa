## Short answer

Для D-тригера значення, записане в наступному такті, строго дорівнює логічному рівню на вході: `Q(t+1) = D`. Завдяки цій характеристичній тотожності карта Карно для функції наступного стану біта безпосередньо є картою збудження входу D відповідного тригера. Для інших тригерів (JK, T, SR) довелося б проводити додаткове перетворення через характеристичні таблиці переходів.[^floyd-digital-fundamentals]

## Detailed explanation

Проєктування синхронних скінченних автоматів (Finite State Machines, FSM) – автоматів Мура та Мілі – складається з вибору способу кодування станів, побудови таблиці переходів і синтезу комбінаційної логіки, яка формує сигнали збудження для входів тригерів пам’яті.[^floyd-digital-fundamentals]

### Характеристичне рівняння та принцип прямої відповідності

Фундаментальна властивість синхронного D-тригера (Data / Delay flip-flop) описується його характеристичним рівнянням:[^floyd-digital-fundamentals]

`Q(t+1) = D`

де `Q(t+1)` (або `Q_next`) – логічний стан прямого виходу тригера після приходу активного фронту тактового імпульсу, а `D` – логічний рівень на інформаційному вході безпосередньо перед тактовим перепадом.

Звідси випливає функція збудження тригера:

`D = Q(t+1)`

Це означає, що для переведення D-тригера в будь-який наступний стан на його вхід збудження `D` необхідно подати саме той логічний рівень, який цей тригер повинен набути в наступному такті. Карта Карно, побудована для змінної наступного стану `Q_i(t+1)` як функції поточного стану та зовнішніх входів, автоматично і без будь-яких проміжних маніпуляцій є картою збудження для входу `D_i` відповідного тригера.[^tocci-digital-systems]

### Порівняння із синтезом на JK-, T- та SR-тригерах

Для інших типів тригерів такої прямої відповідності не існує, тому розробник змушений використовувати таблиці переходів (перехідні або збуджувальні характеристики):[^tocci-digital-systems]

1. **JK-тригер**:
   Його характеристичне рівняння має вигляд `Q(t+1) = J * ~Q(t) + ~K * Q(t)`. Для кожного бажаного переходу необхідно визначати комбінацію входів `J` та `K`:
   - Перехід `0 -> 0`: `J = 0, K = X` (байдужий стан);
   - Перехід `0 -> 1`: `J = 1, K = X`;
   - Перехід `1 -> 0`: `J = X, K = 1`;
   - Перехід `1 -> 1`: `J = X, K = 0`.
   Для кожного біта стану автомата необхідно заповнювати та мінімізувати **дві** окремі карти Карно (одну для `J_i`, іншу для `K_i`), проводячи поелементне перекодування переходів комірка за коміркою. Хоча наявність невизначених станів `X` іноді дозволяє спростити комбінаційну схему, трудомісткість ручного синтезу зростає вдвічі, як і ймовірність помилки.[^tocci-digital-systems]

2. **T-тригер**:
   Зміна стану описується операцією виключного АБО: `Q(t+1) = T ^ Q(t)`. Звідси функція збудження потребує обчислення `T = Q(t) ^ Q(t+1)`. Значення `T = 1` записується в карту Карно лише тоді, коли стан змінюється (`0 -> 1` або `1 -> 0`), що вимагає додаткового порівняння станів.[^floyd-digital-fundamentals]

3. **SR-тригер**:
   Характеризується наявністю забороненого стану (`S = 1, R = 1`), що накладає додаткові обмеження на комбінаторні умови збудження та потребує синтезу двох окремих функцій `S_i` та `R_i`.[^tocci-digital-systems]

### Практичний алгоритм мінімізації функцій збудження

Синтез автомата на D-тригерах зводиться до таких кроків:[^floyd-digital-fundamentals]
1. Складання таблиці переходів автомата із зазначенням поточного стану `Q_n-1 ... Q_0`, вхідних сигналів `X_m ... X_0` та необхідного наступного стану `Q_next_n-1 ... Q_next_0`.
2. Безпосереднє перенесення стовпця наступного стану `Q_next_i` у відповідну карту Карно для змінної `D_i`.
3. Об’єднання одиниць (або нулів) у прямокутні групи максимального розміру за стандартними правилами мінімізації булевих функцій.
4. Отримання мінімальної диз’юнктивної нормальної форми (МДНФ) для входу `D_i`.

### Застосування у сучасних САПР та архітектурі FPGA

В сучасній цифровій схемотехніці та мікроелектроніці (FPGA, CPLD, ASIC) базові логічні комірки (Logic Elements, Configurable Logic Blocks) стандартизовані на основі таблиць перекодування (Look-Up Tables, LUT) та інтегрованих D-тригерів (DFF).[^floyd-digital-fundamentals] Синтезатори мов опису апаратури (Verilog, VHDL, SystemVerilog) безпосередньо обчислюють комбінаційну функцію наступного стану і завантажують її в конфігураційну пам’ять LUT, вихід якої прямо під’єднаний до входу `D` тригера. Відсутність проміжних перетворень робить D-тригер ідеальним промисловим стандартом як для ручного проєктування, так і для автоматизованого синтезу цифрових автоматів.[^floyd-digital-fundamentals]

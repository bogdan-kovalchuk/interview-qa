## Short answer

АЛП є центральним обчислювальним вузлом процесора, який виконує арифметичні (додавання, віднімання, інкремент, декремент) та порозрядні логічні операції (AND, OR, XOR, NOT) над машинними словами. Він приймає операнди з регістрового файлу або шини даних відповідно до коду операції від пристрою керування, а результат записує в регістр призначення та оновлює статусний регістр ознак (прапорці Zero, Sign, Carry, Overflow).[^patterson-hennessy-cod]

## Detailed explanation

Арифметико-логічний пристрій (АЛП, англ. Arithmetic Logic Unit, ALU) – це ключовий цифровий комбінаційний блок центрального процесора (CPU) або мікроконтролера, що відповідає за безпосереднє виконання математичних та логічних перетворень даних. Разом із регістровим файлом, пристроєм керування (Control Unit, CU) та шинами даних він утворює обчислювальне ядро процесора (datapath).[^patterson-hennessy-cod]

### Місце та взаємодія АЛП в архітектурі процесора

У процесорному конвеєрі АЛП функціонує в тісній взаємодії з іншими вузлами:[^mano-digital-design]
- **Пристрій керування (Control Unit)**: дешифрує код поточної інструкції (opcode) та формує багатобітний керуючий сигнал вибору операції (`ALU_control`), який вказує АЛП, яку саме математичну дію слід виконати.
- **Регістровий файл (Register File)**: подає на вхідні порти АЛП значення операндів із регістрів загального призначення (або акумулятора).
- **Пам’ять даних та лічильник команд (PC)**: АЛП використовується не лише для обчислень програми користувача, але й для обчислення ефективних адрес пам’яті (наприклад, додавання базового регістра та зміщення при командах `load`/`store`) та відносних адрес умовних переходів.

### Функціональний склад та виконувані операції

АЛП містить кілька паралельних функціональних секцій, виходи яких комутуються на підсумковий вихідний мультиплексор:[^patterson-hennessy-cod]
1. **Арифметична секція**: багаторозрядний паралельний суматор (із прискореним або префіксним перенесенням), схема інверсії для віднімання в доповняльному коді (two’s complement), блоки інкременту/декременту та апаратні помножувачі.
2. **Логічна секція**: набір паралельних логічних вентилів, що виконують порозрядні булеві операції над машинними словами: AND, OR, XOR, NOT.
3. **Зсувач (Shifter / Barrel Shifter)**: здійснює логічні та арифметичні зсуви слова вліво або вправо за один такт.

### Історичний еталон дискретного АЛП: мікросхема 74x181

Класичним прикладом апаратної реалізації є мікросхема 74181 (74LS181, 74S181) – перший однокристальний 4-бітний АЛП у 24-вивідному корпусі.[^ti-sn74s181-datasheet] Вона приймає два 4-розрядні операнди `A` та `B`, має чотири входи селектора функції `S0..S3`, вхід вибору режиму `M` (Mode) та вхід перенесення `C_n`.
- При `M = 1` мікросхема виконує 16 побітових логічних операцій (AND, OR, XOR, NOR тощо) без урахування перенесень.
- При `M = 0` схема виконує 16 арифметичних операцій (додавання, віднімання `A - B`, декремент, зсув тощо) із формуванням вихідного перенесення.

### Формування прапорців стану процесора (Condition Flags)

Крім безпосереднього результату обчислень, АЛП формує набір апаратних статусних ознак (прапорців), які записуються в регістр стану процесора (PSW / Flags Register) за кожним тактом:[^patterson-hennessy-cod]
- **Z (Zero Flag)**: встановлюється в 1, якщо всі біти результату дорівнюють нулю (`Z = ~(R0 | R1 | ... | R_{n-1})`). Використовується командами порівняння (`CMP`) для виявлення рівності чисел.
- **S або N (Sign / Negative Flag)**: дублює найстарший знаковий біт результату (`R_{MSB}`). Для чисел зі знаком у доповняльному коді одиниця сигналізує про від’ємний результат.
- **C (Carry Flag)**: фіксує біт перенесення з найстаршого розряду суматора при додаванні або біт позики (borrow) при відніманні беззнакових чисел.
- **V або O (Overflow Flag)**: сигналізує про переповнення розрядної сітки знакових чисел (коли результат операції виходить за межі допустимого діапазону). Апаратно прапорець формується елементом XOR між перенесенням у найстарший біт та перенесенням із нього:
  `V = C_{MSB} ^ C_{MSB-1}`

Ці прапорці є фундаментальною основою для команд умовного переходу процесора (`JZ`, `JNZ`, `JGT`, `JLT`), дозволяючи програмам реалізовувати розгалуження, цикли та алгоритмічні рішення.[^mano-digital-design]

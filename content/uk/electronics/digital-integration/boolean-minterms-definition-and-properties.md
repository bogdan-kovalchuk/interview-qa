## Short answer

Мінтерм – це логічний добуток (AND) усіх змінних схеми, де кожна змінна входить прямо або з інверсією. Кожен мінтерм приймає значення логічної 1 рівно для однієї комбінації вхідних сигналів. Будь-яку булеву функцію можна однозначно подати у вигляді суми добутків (OR над мінтермами), що відповідають рядкам таблиці істинності з одиничним результатом.[^floyd-digital-fundamentals]

## Detailed explanation

Мінтерм (кон’юнктивний терм, minterm) є фундаментальним поняттям булевої алгебри та теорії перемикальних функцій. Він становить математичну основу для канонічного аналізу та синтезу комбінаційних логічних схем.[^floyd-digital-fundamentals]

### Математичне визначення

Нехай задано булеву функцію від `n` двійкових змінних: `F(x_1, x_2, ..., x_n)`. 

**Мінтермом** називається логічний добуток (кон’юнкція, операція AND) усіх `n` змінних, у який кожна зі змінних входить рівно один раз – або у прямому вигляді (`x_k`), або у вигляді свого заперечення (інверсії `/x_k` чи `not(x_k)`).[^tocci-digital-systems]

Для системи з `n` змінних існує рівно `2^n` різних можливих мінтермів. Кожен мінтерм традиційно позначають малим символом `m_i`, де числовий індекс `i` (від `0` до `2^n - 1`) є десятковим еквівалентом двійкового набору вхідних змінних, за якого цей мінтерм дорівнює `1`.[^floyd-digital-fundamentals]

Правило формування мінтерма `m_i` за двійковим вектором:
- якщо змінна у відповідному розряді двійкового коду дорівнює `1`, вона записується у прямому вигляді;
- якщо змінна дорівнює `0`, вона записується з інверсією.

**Приклад для трьох змінних (A, B, C), де A – старший біт:**
- `m_0 (000_2) = /A * /B * /C`
- `m_1 (001_2) = /A * /B * C`
- `m_2 (010_2) = /A * B * /C`
- `m_3 (011_2) = /A * B * C`
- `m_4 (100_2) = A * /B * /C`
- `m_5 (101_2) = A * /B * C`
- `m_6 (110_2) = A * B * /C`
- `m_7 (111_2) = A * B * C`

### Фундаментальні властивості мінтермів

Мінтерми мають низку алгебраїчних властивостей, які роблять їх ідеальним математичним базисом для синтезу цифрових автоматів:[^tocci-digital-systems]

1. **Унікальність одиничного значення:**
   Кожен мінтерм `m_i` набуває значення логічної `1` тільки на одному-єдиному з `2^n` можливих вхідних двійкових наборів. На решті `2^n - 1` наборів його значення тотожно дорівнює `0`.

2. **Ортогональність (взаємне виключення):**
   Логічний добуток двох будь-яких різних мінтермів дорівнює тотожному нулю:
   `m_j * m_k = 0` для будь-яких `j != k`.
   Жодні два мінтерми не можуть одночасно прийняти одиничне значення за будь-якої комбінації входів.

3. **Теорема повноти (розклад одиниці):**
   Логічна сума (диз’юнкція, операція OR) усіх `2^n` можливих мінтермів тотожно дорівнює логічній одиниці:
   `sum_(i=0)^(2^n - 1) m_i = 1`

4. **Двоїстість із макстермами (Maxterms):**
   За законами де Моргана інверсія мінтерма є відповідним макстермом (диз’юнктивним термом `M_i`):
   `not(m_i) = M_i`

### Синтез довільної булевої функції за мінтермами

Згідно з теоремою розкладу Шеннона, будь-яку булеву функцію можна однозначно представити у вигляді диз’юнкції тих мінтермів, на яких функція набуває значення `1`. Ця форма подання називається **канонічною диз’юнктивною нормальною формою (КДНФ)** або канонічною сумою добутків (Canonical Sum of Products, SOP):[^floyd-digital-fundamentals]

`F(x_1, ..., x_n) = sum m(i_1, i_2, ..., i_k)`

**Алгоритм побудови КДНФ:**
1. Будують таблицю істинності цільової функції.
2. Знаходять усі рядки таблиці, у яких вихідне значення функції дорівнює `1`.
3. Для кожного такого рядка записують відповідний мінтерм `m_i`.
4. Об’єднують отримані мінтерми логічною операцією «АБО» (OR).

Наприклад, якщо 3-вхідна функція мажоритарного вибору приймає одиничне значення на наборах 3, 5, 6 та 7, її КДНФ має вигляд:
`F = m_3 + m_5 + m_6 + m_7 = (/A * B * C) + (A * /B * C) + (A * B * /C) + (A * B * C)`

### Апаратне втілення в мікроелектроніці

- **Дешифратори (Decoders):** повний двійковий дешифратор розмірності `n:2^n` (наприклад, 74x138 для `n = 3`) є апаратним генератором усіх `2^n` мінтермів на своїх виходах. Підключивши відповідні виходи дешифратора до логічного елемента OR або NAND, інженер може реалізувати будь-яку функцію `n` змінних.[^tocci-digital-systems]
- **Програмовані логічні матриці (PLA, PAL, PROM):** архітектура програмованої логіки містить фіксовану або програмовану матрицю кон’юнкцій (AND), яка формує мінтерми, та матрицю диз’юнкцій (OR), яка сумує їх у цільові вихідні функції.[^floyd-digital-fundamentals]

## Short answer

Часові інтервали астабільного таймера 555 визначаються виразами `t_HIGH ≈ 0,693 * (R_A + R_B) * C` та `t_LOW ≈ 0,693 * R_B * C`. Повний період коливань становить `T = t_HIGH + t_LOW ≈ 0,693 * (R_A + 2*R_B) * C`, а вихідна частота дорівнює `f ≈ 1,44 / ((R_A + 2*R_B) * C)`. Коефіцієнт заповнення імпульсів за високим рівнем становить `D = (R_A + R_B) / (R_A + 2*R_B)`. Подвоєння ємності `C` зменшує частоту генерації рівно вдвічі.[^ti-ne555-datasheet]

## Detailed explanation

### Внутрішня структура та комутація контуру

Класичний астабільний генератор на базі таймера 555 містить внутрішній резистивний подільник із трьох однакових резисторів номіналом по 5 кОм (у біполярній версії), який фіксує опорні напруги внутрішніх компараторів на рівнях `(1/3)*V_CC` (нижній поріг, вхід TRIG, вивід 2) та `(2/3)*V_CC` (верхній поріг, вхід THRES, вивід 6).[^ti-ne555-datasheet]

Зовнішній частотозадавальний ланцюг складається з резисторів `R_A` (підключеного між лінією живлення `V_CC` і виводом розряду DISCH, вивід 7), `R_B` (між виводом 7 та об’єднаними виводами 2 і 6) і конденсатора `C` (між об’єднаними виводами 2, 6 та землею GND). Під час роботи напруга на конденсаторі `v_C(t)` неперервно коливається між пороговими рівнями `(1/3)*V_CC` та `(2/3)*V_CC` без необхідності зовнішньої синхронізації.[^fiore-555-timer]

### Фаза заряду (стан HIGH)

На початку циклу внутрішній RS-тригер перебуває у скинутому стані, що робить вихід (вивід 3) активним високим (HIGH), а внутрішній розрядний NPN-транзистор, колектор якого виведений на пін 7, – закритим (відсічка). Струм від джерела живлення `V_CC` протікає через послідовно з’єднані резистори `R_A` та `R_B`, заряджаючи конденсатор `C`.[^aac-555-circuits]

Загальне диференціальне рівняння заряду RC-кола має вигляд:
`v_C(t) = V_final - (V_final - V_initial) * exp(-t / ((R_A + R_B) * C))`

У цій фазі конденсатор заряджається у напрямку до `V_final = V_CC`, починаючи з напруги `V_initial = (1/3)*V_CC`. Процес триває доти, доки напруга `v_C` не досягне верхнього порогу `(2/3)*V_CC`:
`(2/3)*V_CC = V_CC - (V_CC - (1/3)*V_CC) * exp(-t_HIGH / ((R_A + R_B) * C))`
`(2/3)*V_CC = V_CC - (2/3)*V_CC * exp(-t_HIGH / ((R_A + R_B) * C))`
`(1/3)*V_CC = (2/3)*V_CC * exp(-t_HIGH / ((R_A + R_B) * C))`
`1/2 = exp(-t_HIGH / ((R_A + R_B) * C))`
`exp(t_HIGH / ((R_A + R_B) * C)) = 2`

Логарифмуючи обидві частини, отримуємо аналітичний вираз для тривалості високого рівня:[^ti-ne555-datasheet]
`t_HIGH = ln(2) * (R_A + R_B) * C ≈ 0,69315 * (R_A + R_B) * C`

### Фаза розряду (стан LOW)

Коли напруга на конденсаторі перевищує `(2/3)*V_CC`, верхній компаратор спрацьовує і встановлює RS-тригер (SET). Це призводить до перемикання виходу (вивід 3) у низький стан (LOW) і відкриття внутрішнього розрядного NPN-транзистора до стану насичення, приєднуючи вивід 7 практично до шини GND.[^fiore-555-timer]

Тепер резистор `R_A` підключений безпосередньо між `V_CC` і заземленим колектором виводу 7, споживаючи струм `I = V_CC / R_A`, але не беручи участі в перезаряді ємності. Конденсатор `C` розряджається на землю виключно через резистор `R_B` та відкритий розрядний транзистор:[^aac-555-circuits]
`v_C(t) = V_initial * exp(-t / (R_B * C))`

Розряд починається з `V_initial = (2/3)*V_CC` і завершується, коли напруга падає до нижнього порогу `(1/3)*V_CC`, активуючи нижній компаратор:
`(1/3)*V_CC = (2/3)*V_CC * exp(-t_LOW / (R_B * C))`
`1/2 = exp(-t_LOW / (R_B * C))`
`t_LOW = ln(2) * R_B * C ≈ 0,69315 * R_B * C`

Нижній компаратор знову скидає RS-тригер, закриває розрядний ключ, і цикл повторюється нескінченно.

### Період, частота та коефіцієнт заповнення

Повний період коливань `T` дорівнює сумі інтервалів заряду та розряду:[^ti-ne555-datasheet]
`T = t_HIGH + t_LOW = ln(2) * (R_A + R_B) * C + ln(2) * R_B * C = ln(2) * (R_A + 2*R_B) * C`
`T ≈ 0,69315 * (R_A + 2*R_B) * C`

Частота генерації є оберненою величиною до періоду:
`f = 1 / T = 1 / (ln(2) * (R_A + 2*R_B) * C) ≈ 1,4427 / ((R_A + 2*R_B) * C) ≈ 1,44 / ((R_A + 2*R_B) * C)`

Коефіцієнт заповнення (duty cycle) за високим рівнем визначається як відношення часу `t_HIGH` до повного періоду `T`:
`D = t_HIGH / T = (ln(2) * (R_A + R_B) * C) / (ln(2) * (R_A + 2*R_B) * C) = (R_A + R_B) / (R_A + 2*R_B)`

Оскільки опір `R_A` принципово більший за нуль (`R_A > 0`), чисельник завжди перевищує половину знаменника, тому в стандартній конфігурації коефіцієнт заповнення `D` завжди строго більший за 50 % (зазвичай у діапазоні від 51 % до 99 %).[^fiore-555-timer] Якщо потрібен коефіцієнт заповнення менше 50 % або рівно 50 %, паралельно до `R_B` включають діод (наприклад, 1N4148 катодом до піна 6/2), який шунтує `R_B` під час заряду, забезпечуючи роздільні шляхи заряду через `R_A` і розряду через `R_B`.

### Інженерні фактори та похибки на практиці

1. Залежність частоти від ємності: вираз `f ~ 1/C` є строго лінійним щодо оберненої ємності, тому подвоєння номіналу `C` призводить до зменшення вихідної частоти рівно вдвічі при незмінному коефіцієнті заповнення.[^aac-555-circuits]
2. Вплив напруги живлення: завдяки логометричному принципу внутрішнього подільника пороги `(1/3)*V_CC` і `(2/3)*V_CC` відстежують коливання напруги живлення, тому в ідеалі частота не залежить від `V_CC`. Проте в біполярних NE555 напруга насичення розрядного транзистора `V_CE(sat) ≈ 0,1...0,2 В` вносить невелику температурну і напругову нестабільність.[^ti-ne555-datasheet]
3. Обмеження номіналів: мінімальне значення `R_A` зазвичай обмежують величиною 1 кОм для захисту внутрішнього транзистора розряду від перевантаження струмом, а сумарний опір `R_A + R_B` обмежують значенням порядку кількох мегаом через вплив вхідних струмів зміщення компараторів (до 0,5 мкА у NE555).

## Short answer

Для заданих параметрів часові інтервали становлять `t_HIGH ≈ 39,5 мс` та `t_LOW ≈ 32,6 мс` при повному періоді `T ≈ 72,1 мс`. Вихідна частота коливань дорівнює `f ≈ 13,9 Гц`, а коефіцієнт заповнення за високим рівнем становить `D ≈ 54,8 %`. Реальні параметри схеми відрізнятимуться від розрахункових через виробничі допуски компонентів, струм витоку конденсатора та затримки компараторів таймера.[^ti-ne555-datasheet]

## Detailed explanation

### Розрахунок тривалостей імпульсу та паузи

В астабільному режимі таймера 555 тривалість високого рівня вихідного сигналу `t_HIGH` визначається часом заряду конденсатора `C` від напруги `(1/3)*V_CC` до `(2/3)*V_CC` через послідовний ланцюг резисторів `R_A` та `R_B`:[^ti-ne555-datasheet]
`t_HIGH = ln(2) * (R_A + R_B) * C ≈ 0,69315 * (R_A + R_B) * C`

Підставляючи задані числові значення:
- `R_A = 10 кОм = 10 * 10^3 Ом`
- `R_B = 47 кОм = 47 * 10^3 Ом`
- `C = 1 мкФ = 1 * 10^(-6) Ф`

Отримуємо:
`t_HIGH = 0,69315 * (10 * 10^3 + 47 * 10^3) * 1 * 10^(-6) = 0,69315 * 57 * 10^(-3) с ≈ 39,51 мс`

Тривалість низького рівня вихідного сигналу `t_LOW` визначається часом розряду конденсатора від `(2/3)*V_CC` до `(1/3)*V_CC` виключно через резистор `R_B` і внутрішній відкритий транзистор виводу розряду (DISCH, пін 7):[^fiore-555-timer]
`t_LOW = ln(2) * R_B * C ≈ 0,69315 * R_B * C`
`t_LOW = 0,69315 * (47 * 10^3) * 1 * 10^(-6) = 0,69315 * 47 * 10^(-3) с ≈ 32,58 мс`

### Період, частота та коефіцієнт заповнення

Повний період коливань генератора `T` дорівнює сумі двох напівперіодів:[^aac-555-circuits]
`T = t_HIGH + t_LOW ≈ 39,51 мс + 32,58 мс = 72,09 мс ≈ 72,1 мс`

Або безпосередньо через аналітичну формулу:
`T = ln(2) * (R_A + 2*R_B) * C = 0,69315 * (10 + 2 * 47) * 10^3 * 10^(-6) = 0,69315 * 104 * 10^(-3) с ≈ 72,09 мс`

Частота генерації визначається як обернена величина періоду:
`f = 1 / T = 1 / 0,07209 с ≈ 13,87 Гц`

При використанні спрощеного інженерного коефіцієнта з даташита (`1,44`):[^ti-ne555-datasheet]
`f ≈ 1,44 / ((R_A + 2*R_B) * C) = 1,44 / (104 * 10^3 * 1 * 10^(-6)) = 1,44 / 0,104 ≈ 13,85 Гц`

Коефіцієнт заповнення (duty cycle) для високого рівня становить:
`D = t_HIGH / T = 39,51 мс / 72,09 мс ≈ 0,5481` (або `54,8 %`)

В аналітичному вигляді вираз не залежить від ємності `C`:
`D = (R_A + R_B) / (R_A + 2*R_B) = (10 + 47) / (10 + 94) = 57 / 104 ≈ 0,5481`

### Фізичні та технологічні чинники розбіжності розрахунку з практикою

У реальній схемі отримані результати завжди відхилятимуться від ідеального математичного розрахунку під впливом наступних фізичних факторів:[^ti-ne555-datasheet][^fiore-555-timer]

1. Допуски пасивних компонентів: електролітичні або танталові конденсатори ємністю 1 мкФ зазвичай мають виробничий допуск ±20 % (а керамічні X7R – також виражену залежність ємності від прикладеної постійної напруги зміщення DC-bias). Резистори мають допуск ±1 % або ±5 %. Якщо фактична ємність виявиться рівною 1,2 мкФ, тривалості зростуть на 20 %, а частота впаде до ~11,6 Гц.
2. Струм витоку конденсатора (leakage current): для електролітичних конденсаторів струм витоку еквівалентний резистору, підключеному паралельно `C`. Цей струм зменшує ефективний зарядний струм на етапі заряду і прискорює розряд, що збільшує `t_HIGH`, дещо зменшує `t_LOW` і знижує сумарну частоту коливань.
3. Залишкове падіння напруги на розрядному транзисторі: внутрішній NPN-транзистор піна 7 у стані насичення має напругу `V_CE(sat) ≈ 0,1...0,2 В`. Через це конденсатор розряджається не до чистої землі, а до `V_CE(sat)`, що дещо спотворює нижню точку траєкторії розряду відносно ідеального порогу `(1/3)*V_CC`.
4. Внутрішній подільник мікросхеми: опір внутрішніх трьох резисторів по 5 кОм має індивідуальний технологічний розкид до ±20 % (хоча коефіцієнт їхнього взаємного узгодження на одному кристалі набагато кращий, близько 1 %). Це викликає невеликий зсув порогових напруг 1/3 і 2/3 від номінальних значень.
5. Затримка поширення компараторів: час реакції внутрішніх компараторів біполярного 555 становить типово 100–300 нс. На низькій частоті близько 14 Гц ця затримка абсолютно нехтовно мала (складає менше 0,001 % періоду), але стає домінуючим джерелом похибки на частотах понад 100 кГц.

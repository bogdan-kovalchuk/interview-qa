## Short answer

A half adder adds two binary bits `A` and `B` without considering an incoming carry. The sum bit `S` is generated by an `XOR` gate according to `S = A ^ B`, producing `1` only when the inputs differ. The carry-out bit `C` is generated by an `AND` gate according to `C = A & B`, taking the value `1` only when both inputs are `1`.[^floyd-digital-fundamentals]

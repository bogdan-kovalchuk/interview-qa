## Short answer

The atomic number `Z` equals the number of protons in the nucleus and defines the chemical element; the mass number `A` equals the sum of protons and neutrons.[^openstax-atomic-structure] For a neutral atom, the number of electrons also equals `Z`, but an ion can have a different number of electrons. In silicon, `Z = 14`, and the most common isotope has `A = 28`.[^openstax-atomic-structure]

## Detailed explanation

The atomic number `Z` is the number of protons in the nucleus; it is what defines which chemical element the atom belongs to.[^openstax-atomic-structure] The mass number `A` is the integer number of nucleons in the nucleus: protons plus neutrons. Therefore, the number of neutrons can be found as `A - Z`.[^openstax-atomic-structure]

One should not confuse the mass number with the average atomic mass of an element in the periodic table. The mass number describes a specific isotope, whereas the atomic mass of a naturally occurring element is a weighted average of isotope masses; isotopes of the same element have the same `Z`, but different numbers of neutrons.[^openstax-atomic-structure]

Example: in the most common isotope, silicon-28, `Z = 14` and `A = 28`, so the nucleus contains 14 protons and 14 neutrons. A neutral atom of this isotope also has 14 electrons; for an ion, this latter statement is no longer necessarily true.

Therefore, to find the number of neutrons of a specific isotope, one subtracts the atomic number from the mass number: `N = A - Z`. For example, the isotopes silicon-29 and silicon-30 have the same 14 protons, but 15 and 16 neutrons, respectively. They remain atoms of the same element because its chemical identity is defined specifically by the nuclear charge, that is, the number of protons.[^openstax-atomic-structure]

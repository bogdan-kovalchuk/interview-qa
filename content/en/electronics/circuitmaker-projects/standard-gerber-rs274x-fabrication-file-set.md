## Short answer

A complete manufacturing set includes top and bottom copper layers, top and bottom solder mask layers, and silkscreen overlay files. It additionally requires the board outline profile on a mechanical layer and an NC Drill file for hole coordinates and tool sizes. If any of these files is missing, the fab house cannot manufacture or machine the bare PCB.[^udemy-electronics-course]

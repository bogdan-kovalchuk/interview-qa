Чим shallow copy відрізняється від deep copy для контейнера з вкладеними mutable objects?	<span class="key">Shallow copy створює новий зовнішній контейнер, але внутрішні об'єкти залишаються спільними посиланнями; deep copy рекурсивно копіює все до кінця.</span> Для <code>a = [[1, 2]]</code>: після <code>s = copy.copy(a)</code> вираз <code>s[0] is a[0]</code> — <code>True</code>, і mutation <code>s[0]</code> змінює <code>a[0]</code>. Коли <code>isinstance()</code> є доречним runtime check, а коли protocol або duck typing робить код менш зв’язаним із concrete classes?	<span class="key"><code>isinstance()</code> доречний на межі API для швидких guards, у dispatch-логіці (наприклад серіалізація) та з ABC для virtual subclasses.</span> Проте перевірка щодо конкретного класу tightly couple до ієрархії успадкування. <code>typing.Protocol</code> з <code>@runtime_checkable</code> та duck typing перевіряють поведінку (наявність методів/атрибутів) без вимоги конкретних класів.

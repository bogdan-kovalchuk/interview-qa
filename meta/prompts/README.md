# Промпти для наповнення

П'ять промптів попереднього проєкту: генерація й рев'ю карток, генерація й рев'ю фронтів,
аудит покриття. Вистраждані на 392 картках.

**Потребують адаптації** під нову схему, перш ніж ними користуватись:

- дев'ять типів питань замість шести, і типоспецифічні набори секцій;
- `Short answer` більше не завжди «відповідь»: для `coding` це `Solution outline`,
  для `system-design` – `Architecture summary`, для `behavioral` – `Answer framework`;
- обов'язковий `Evaluation guide` для `middle` і `senior`;
- `source_id` і прив'язка тверджень до джерел;
- двомовність і глосарій;
- ліміт довжини змінено: 2–5 речень, м'яке попередження понад 90 слів.

Поки адаптації немає – читати як зразок структури, не виконувати дослівно.

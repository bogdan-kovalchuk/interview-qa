# Картки Anki

Колоду будує `tools/iqa/anki.py` (`genanki`) з `dist/export/questions.json`; `content/` він не
читає. Що виміряно на реальних колекціях – `meta/measurements.md`.

## Note type

**Рівно один: `Interview QA Basic`**, визначений один раз в `anki/notetype/`:

| Файл | Що в ньому |
|---|---|
| `fingerprint.json` | `model_id`, назви й `id` п'яти полів, `id` єдиного шаблону |
| `front.html`, `back.html` | розмітка картки |
| `card.css` | стилі; блоки `@font-face` генеруються з `anki/fonts/fonts.json` при збірці |

**Note type заморожений**: колода вже вийшла (`deck-v2026.10.1`). Зміна `model_id`, полів або
кількості шаблонів не дає помилки – Anki тихо зливає note types, зсуває поля на інші ord і створює
зайві картки (виміряно). Білдер пише поля **за іменем**, ідентифікатори бере з
`fingerprint.json`, шаблон рівно один. Стилі й розмітку шаблонів змінювати безпечно.

| Поле | Звідки | Показується |
|---|---|---|
| `Front` | мітка треку + `title` + блок `Question code`, якщо він є | так |
| `Back` | `Short answer` як HTML, без citation-токенів | так |
| `Reference` | `https://bogdan-kovalchuk.github.io/interview-qa/{lang}/q/{id}/` | посилання «Розгорнуте пояснення» |
| `Sources` | `sources`: один рядок на джерело, `title` як текст посилання | приховано |
| `QID` | `id` | ні |

## Коли картка з'являється

**Картка цією мовою їде тоді й лише тоді, коли `Short answer` цією мовою написаний.** Порожніх
чи призупинених карток не буває: імпорт не змінює стан карток, які вже є в колекції, тож стан
першої появи остаточний, і порожня картка стала б вічним шумом у черзі.

## GUID

```
guid = base91(sha256("iqa:v1:" + id).digest()[:8])         # українська колода
guid = base91(sha256("iqa:v1:en:" + id).digest()[:8])      # англійська колода
```

Одне джерело, без мапи legacy (`tools/iqa/guid.py`, захищено еталонними векторами в тестах).
Сіль фіксована назавжди: її зміна дає масові дублікати і втрату розкладу. Окремий простір для
англійської потрібен, бо `id` у двох мов один: інакше імпорт другого пакета перезаписав би перший.

## Пакети, колоди, теги

**Один пакет – рівно одна мова.** Якщо тексту цією мовою немає, картка не їде; іншу мову у
зворот не підставляють.

```
python -m iqa deck --language {uk,en} [--track python|embedded|electronics]
```

| Пакет | Корінь колод |
|---|---|
| `Interview QA - Full Library.apkg` | `Interview QA::` |
| `Interview QA (EN) - Full Library.apkg` | `Interview QA (EN)::` |

`--track` дає **підмножину тих самих нотаток** – ті самі GUID і колоди, тож трековий пакет і Full
Library імпортуються в одну колекцію без дублікатів. Реліз тегом `deck-v*` публікує вісім пакетів:
Full Library, Python, Embedded і Electronics, кожен обома мовами, з `.sha256`.

**Колода – завжди тема:** `Interview QA::Python::01 Fundamentals`. Назви англійські для обох мов.
Номер секції – її позиція в `meta/taxonomy.md`, двозначний, бо Anki сортує колоди за абеткою.
Нові картки в колоді стоять у порядку секції на сайті: `meta/order.yml`, а без запису там – за ID.
Імпорт не переміщує наявні картки між колодами (виміряно), тож перейменування колоди в уже
імпортованій колекції робиться один раз руками в Anki.

**Теги** генеруються, не пишуться руками: `topic::{track}::{section}` і `qid::{id}`. Теги в
пакеті замінюють теги нотатки повністю.

`.apkg` не комітиться: пакети збираються в `anki/dist/` і публікуються як GitHub Release assets.

## Що безпечно змінювати

Anki зіставляє нотатки за GUID, а розклад живе на картках. Тому зміна будь-якого **вмісту** –
полів, тегів, перекладу – безпечна й зберігає історію повторень (виміряно).

| Без явної міграції заборонено | Наслідок |
|---|---|
| зміна `id` питання | інший GUID: дублікат, історія втрачена |
| зміна формули або солі GUID | те саме, але масово |
| зміна `model_id`, полів, кількості шаблонів | тиха структурна корупція колекції |

Видалене з репозиторію питання імпорт з колекції не прибирає: його видаляють в Anki пошуком
`tag:qid::<id>`.

## Шрифти

| Роль | Шрифт |
|---|---|
| Питання | Literata (OFL) |
| Відповідь | Golos Text (OFL) |
| Код | JetBrains Mono (OFL) |

Файли – підмножини `latin` + `cyrillic` в `anki/fonts/`, з підкресленням на початку імені (інакше
Anki видалить їх як невикористані). Стрілки U+2190 і U+2192 підмножини не покривають, тому в
контенті вони заборонені: пишіть словами або `->` у коді.
